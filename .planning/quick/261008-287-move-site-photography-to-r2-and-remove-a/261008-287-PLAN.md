# Move site photography to R2, remove `assets/photography/` from git

Rule (CLAUDE.local.md, 2026-10-08): every uploaded image lives in Cloudflare R2, never Supabase Storage;
site photography goes to R2 first and pages use `/photos/site/<name>` (immutable one-year cache, so a
changed picture is a new file name). Nothing about how a page looks changes: the same bytes, a new address.

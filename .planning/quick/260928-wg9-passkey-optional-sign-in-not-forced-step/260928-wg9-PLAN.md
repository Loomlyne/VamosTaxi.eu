# Dashboard passkey is an option, not a forced step

Owner rule (2026-09-28): password, magic link, e-mail code and passkey are sign-in options the
admin chooses in his profile. Any one of them lets him in. Adding a passkey must not force it.

Live state: admin has 1 row in auth.webauthn_credentials, no MFA factor. Because of 26.1-25 the
gate sends every password / magic-link session to a passkey step-up, while the dashboard login
hides the "Sign in with a passkey" button (`showPasskey … && !isOps`).

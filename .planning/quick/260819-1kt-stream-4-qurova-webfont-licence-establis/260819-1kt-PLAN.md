## Provenance — read out of the TTF `name` tables themselves

`design-system/assets/fonts/Qurova-{Light,Regular,Medium,SemiBold,Bold}.ttf`:

- Copyright: `©2025 by Prioritype Co.  All Rights Reserved.`
- Trademark: `Qurova trademark of Prioritype Co`
- Designer: `Prio Nurokhim Aji` · DesignerURL: `www.prioritypeco.com`
- Version 1.000, UniqueID `...;FL720`
- **No `LicenseDesc` (name ID 13) and no `LicenseURL` (name ID 14) entry at all.**

`Poppins-*.ttf` in the same folder, by contrast, carries:

- `LicenseDesc`: "This Font Software is licensed under the SIL Open Font License, Version 1.1..."
- `LicenseURL`: `https://scripts.sil.org/OFL`
- Copyright: `Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins)`,
  Indian Type Foundry.

So Qurova is a commercial retail face with reserved rights; Poppins is OFL 1.1. Serving Qurova
from production without a web licence is unlicensed redistribution of a commercial font.

**`design-system/assets/fonts/OFL.txt` does not exist.** `docs/build/OPEN-QUESTIONS.md` Q4 says
"the only licence on file (`design-system/assets/fonts/OFL.txt`) covers Poppins" — that premise
is false. `design-system/tokens/fonts.css` line 2 points at the same non-existent file. A
repository-wide search excluding `archive/` returns no LICENSE, OFL or EULA file anywhere.

## C25 — the new conflict

`app/vamos-locale.js` lines 296–301: when Arabic is selected the runtime injects a `<link>` to
`https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic:wght@400;500;600;700&display=swap`.
Line 289 sets `--vt-font-display` to
`'Noto Sans Arabic','Qurova','Poppins',system-ui,sans-serif` and line 288 sets `--vt-font-body`
to `'Noto Sans Arabic','Poppins',system-ui,sans-serif`.

Severity **high**, and it is a **data-protection** finding, not a licensing one — Noto Sans
Arabic is OFL, so the font itself is free to vendor. The problem is the hotlink: every Arabic
page load discloses the visitor's IP address and user-agent to Google, a party the privacy
page's subprocessor list does not name (that list is Cloudflare, Supabase, Stripe, Resend,
Mapbox, AeroDataBox and Sentry per Q21, answered 17 Aug 2026), and it fires before any consent
interaction. German courts have found hotlinked Google Fonts to breach GDPR on exactly this
reasoning. It also contradicts the repository's own vendoring practice — Lucide icons, both type
families and Lenis are all vendored locally.

Remedy to **record, not perform**: vendor Noto Sans Arabic (or another OFL Arabic face) into
`design-system/assets/fonts/` and drop the CDN link. That is a code change and belongs in the
same reviewable pass as the other mock edits in the checklist's §I. Disposition: **OPEN**.

## The recommendation the record should reach

Buy the $69 Web Font licence, and check the pageview cap against expected traffic before
assuming it is sufficient.

- $69 against a 2–3 week launch and a bound design system whose display face *is* the brand is
  not a real trade-off. The cost of the alternative — reworking every display setting across 30+
  screens — dwarfs it by orders of magnitude.
- The binding risk is not the price, it is the 100,000 monthly pageview cap on one website. A
  public transfer site running paid acquisition can pass that, and the moment it does the licence
  is breached silently. The record must say who watches the number.
- Duration is unstated on the foundry's page. Perpetual-versus-annual is a written question to
  put to Prioritype before purchase, because an annual licence is a recurring obligation someone
  has to remember in year two.
- The purchase is the owner's to make — their money, their brand — but it is not a *design*
  decision. That is exactly why the rendered fallback exists as insurance rather than as the
  expected path.

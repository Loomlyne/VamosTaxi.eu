# 04.3 CONTEXT — blended distance bands + OPS rate book

**Gathered:** 2026-09-06
**Status:** Ready for planning
**Parent:** Phase 4 quote engine (decimal insert). Phase 7 live Stripe charge stays paused until a live `rate_versions` row exists.

## Phase boundary

Staff can enter the owner Switzerland matrix on **OPS Pricing & Routes**. After **Publish** (`draft → live`), new quotes use blended km bands + class floors + region %. Stripe charges that snapshot. Already-quoted bookings stay frozen. Public UI stays `CHF 000` until publish.

## Locked (owner 2026-09-06)

- Engine table = **sheet 2** (inside Switzerland). Sheet 1 (airport → anywhere) is reference only — not charged.
- Classes: Economy floor **80** (Sedan). Business floor **100** (E-Class). Van floor **150** (Vito). **V-Class out.**
- One band table for every class. Floors only change the first 20 km.
- **Blended** math: first 20 km = class floor (lump). Then 21–50 @ 3.80/km, 51–100 @ 3.40, 101–150 @ 3.20, 151–200 @ 3.00, 200+ @ 2.80.
- Region % if **pickup OR dropoff** is in that named zone: Jungfrau/Interlaken **+10%**, Ticino/Lugano **+15%**, Engadin/St. Moritz **+20%**, Geneva/Lake Geneva **+20%**, Remote Alpine **+25%**.
- Night / extra stop / child seat / meet-greet / ski: **not in the calculation** until the owner adds them on OPS. Do not invent those amounts.
- Source of truth = OPS Pricing. **Publish still required** (keep `quote-publish.md`). Save on a draft does not change live quotes. After publish, new quotes and Stripe charges use the new snapshot. In-flight snapshots frozen (D-26).
- Stripe has **no second price list**. Checkout Session amount = quote snapshot. No Stripe Price IDs.
- Do not invent CHF. Owner numbers live in `docs/build/OWNER-ANSWERS.md` D-46 sitting. Migrations must not insert a `status='live'` row.
- Do not execute on `phase-7`. After plan approval, branch from `origin/main`. No PR/merge/`main`/live DNS this phase unless the owner says ship.
- Do not `state.begin-phase` (would steal Phase 12 / v1.1). Do not `phases.clear`.

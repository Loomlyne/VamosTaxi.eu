# Phase 30 — UI Design Contract

> Visual and interaction contract for Phase 30, vehicle class lifecycle. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Surface: dashboard (ops) only. Pricing page class rows, Retire and Go live dialogs, Retired list, Chauffeurs screen, Assign picker. Nothing else on Pricing moves.

Sources: `.planning/decisions/2026-10-11-fleet-lifecycle.md` (signed, source of truth), `30-CONTEXT.md`, `30-DESIGN-SIGNED.md` (five signed sheets), the unsigned prototype `30-prototype-wip.patch` (raw material only), committed code at HEAD, the Vamos design system tokens and bundle.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable: `.dc.html` mocks on the vendored Vamos kit, no React/Vite build) |
| Preset | not applicable |
| Component library | Vamos design system bundle `VamosTaxiDesignSystem_245af1` (Badge, Button, IconButton, Dialog, Textarea, Icon) plus `OpsTable` (dc-import) |
| Icon library | vendored Lucide set through the kit `Icon` (no archive icon exists, so Retire is `eye-off`) |
| Font | Qurova (display, figures, dialog titles) + Poppins (UI) |

Laws that bind every element below: no glow (`--vt-shadow-accent:none`, `.vt-input--focus{box-shadow:none}` stay in every touched `.dc.html`), no tinted yellow (no `--vt-yellow-50..300` backgrounds, no `Badge tone="warning"`, no `Alert tone="accent"`), four languages in the same pass, `CHF 000` placeholders, logical properties for RTL, native scrolling.

## Spacing Scale

Declared values (all multiples of 4, taken from `--vt-space-*`):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gap, gap between name and badge when wrapped |
| sm | 8px | Gap between Missing line and name, between dialog checklist rows, button pair gap |
| md | 16px | Dialog body padding steps, Retired row padding, section gap inside dialogs |
| lg | 24px | Gap between the class table and the Retired section |
| xl | 32px | Not used by new elements (page rhythm owned by Pricing) |

12px (`--vt-space-3`) is allowed for the gap between the Retired head and its first row and between a Retired row's text block and its button when stacked.

Exceptions:
- Hit area of the Draft badge button is 44px high while the visible badge stays 24px (padding is invisible, so the row does not grow). The signed sheet had a 32px button; this contract replaces it.
- Dialog close `IconButton` stays the kit 36px (kit exception); the 44px Cancel button next to it is the touch-safe path.
- Forbidden from the prototype: `padding:10px 16px` on the Retired head (off-scale), `max-width:78px` on the class cell.

## Typography

Four sizes, two weights. Badge 11px uppercase is kit-owned (`--vt-label-sm`) and not counted as a page size.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Body | 16px (`--vt-body-md`) | 400 | 1.6 | Dialog body sentences, Retire reason input text |
| Label | 14px (`--vt-body-sm`) | 600 for names and item labels, 400 for sentences | 1.45 | Class name in a Retired row, checklist labels, reason text in a Retired row, why-line, Assign muted line, chauffeur class name |
| Small | 13px (`--vt-body-xs`) | 400 | 1.45 | "Missing: ..." line, chauffeur retired flag, count in the Retired head, field hints |
| Heading | 20px (`--vt-heading-3`, Qurova) | 600 | 1.18 | Dialog titles only (kit `Dialog`) |

The Retired section head uses 16px Qurova at weight 600 (same step as the Body size, display face). Weight 500 is not used anywhere (the prototype used it in places; remove).

Button labels, badges, kickers: UPPERCASE through the kit (`--vt-label-sm` tracking). Everything else is sentence case.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F6F6F6` page ground, `--vt-bg-surface` white panels | Pricing page ground, table, dialog surface, Retired list |
| Secondary (30%) | Charcoal `#1E1F1F` | Ops sidebar, LIVE badge (`Badge tone="inverse"`), RETIRED badge text, secondary buttons (EDIT CLASS, CANCEL, BRING BACK), `--vt-border-subtle` hairlines |
| Accent (10%) | Yellow `#FDC20B` | See reserved list |
| Destructive / semantic | `--vt-danger` | Chauffeur "Retired class" flag, missing items in the Go live checklist, failed-action error text |
| Positive | `--vt-success` | Done items in the Go live checklist only |

Accent reserved for: ADD CLASS (existing primary), RETIRE confirm in the Retire dialog (primary), GO LIVE in the Go live dialog (primary, only while enabled). Nothing else is yellow: not badges, not the Draft badge, not the missing line, not icons, not the Retired list.

Rules:
- LIVE = `Badge tone="inverse"` (charcoal). DRAFT = `Badge tone="outline"`. RETIRED = `Badge tone="neutral"`.
- Retire is reversible, so it is not red: the row action and the editor-foot button are neutral charcoal. `--vt-danger` is never used on a Retire control. Red stays for the data problem (flag, missing item).
- No tinted panels for Draft or Retired rows. Row background is the table's own surface in all three states. Retired rows use white with a `--vt-border-subtle` hairline.
- Disabled GO LIVE uses the kit disabled button style (no opacity tricks, no custom grey).

## Component and tone inventory

| Need | Component | Props / tone |
|------|-----------|--------------|
| State in class cell | kit `Badge` | Live `tone="inverse"`, Draft `tone="outline"`, Retired `tone="neutral"` (Retired list only) |
| Draft badge click target | native `<button type="button">` wrapping the Badge | `min-height:44px`, no background, no border, `aria-haspopup="dialog"`, `aria-label` "Draft: see what is missing" in 4 languages |
| Retire row action | kit `IconButton` | icon `eye-off`, size 44 at touch widths, `aria-label`/`title` = "Retire" |
| Retire dialog | kit `Dialog` size `sm` | title, subtitle = class name, `Textarea` max-length 140, Buttons CANCEL (`secondary`) and RETIRE (`primary`) |
| Go live dialog | kit `Dialog` size `sm` | checklist rows (`Icon circle-check` success / `circle-alert` danger + label), why-line, Buttons EDIT CLASS (`secondary`) and GO LIVE (`primary`) |
| Retired list | native `<section>` with a head `<button>` | `Icon chevron-down` (open) / `chevron-right`, mirrored by logical `dir` handling (use `chevron-down`/`chevron-up` as in the prototype to avoid direction flip), count |
| Bring back | kit `Button` | `variant="secondary"` `size="sm"` (36px) at ≥681, `size="md"` (44px) at ≤680 |
| Chauffeur flag | `Icon circle-alert` size 14 + 13px text | `--vt-danger` |
| Editor foot Retire | existing `[data-vt-foot-del]` slot of `OpsTable` | label "Retire", icon `eye-off`, neutral charcoal text (new props `deleteLabel`, `deleteIcon`, `deleteTone` on `OpsTable`; `onAskDelete` keeps the existing handler name) |

Never restyle these in local CSS. Local `[data-*]` rules are for layout only (cell stacking, row wrapping).

Dialog behaviour the kit does not provide, required here (match the existing hide dialog in `OpsPricing`): Escape closes; focus moves to the first focusable control on open (Cancel for Retire, Edit class for Go live) and returns to the trigger on close; Tab stays inside while open; scrim click closes only when nothing is being saved.

## Copywriting Contract

All strings go in the page `T` tables and in `app/vamos-i18n-dict.js` in the same pass. Class names are Latin in every language (D-14a) and sit in `data-vt-no-i18n` with `unicode-bidi:isolate` in Arabic. Numbers and counts sit in `vt-dir-keep`. Strings with a number or a name are `patterns` entries or split nodes (`{{ value }}` splits a sentence into text nodes: translate the parts, wrap the value in `vt-dir-keep` + `data-vt-no-i18n`). German is Swiss ("ss", never "ß"). The Arabic word for chauffeur is the one the dictionary already uses (prototype: سائق); do not introduce a second term.

## States

Every element, every state. "Kit" means the kit component's own style, never restyled.

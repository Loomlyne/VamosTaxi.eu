# Phase 30 — UI Design Contract

> Visual and interaction contract for Phase 30, vehicle class lifecycle. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Surface: dashboard (ops) only. Pricing page class rows, Retire and Go live dialogs, Retired list, Chauffeurs screen, Assign picker. Nothing else on Pricing moves.
> **Governing fact:** the owner signed the five design sheets on 2026-10-11 (`30-DESIGN-SIGNED.md`; pictures `screens/sheet-1-table.png` to `sheet-5-chauffeurs.png`). This contract describes exactly what those sheets show. Anything the sheets do not show is under "Open questions for the owner" and is not built until he signs it.

Sources: `.planning/decisions/2026-10-11-fleet-lifecycle.md` (signed, source of truth), `30-CONTEXT.md`, `30-DESIGN-SIGNED.md`, the five signed sheets, the unsigned prototype `30-prototype-wip.patch` (raw material for strings only), committed code at HEAD, the Vamos design system tokens and bundle.

**Focal point:** the Pricing class table (the "Distance rules" pane). The Live/Draft badge in the class cell is the one new thing a reader's eye should land on; every dialog and the Retired list hang off that table.

Laws that bind every element below: no glow (`--vt-shadow-accent:none`, `.vt-input--focus{box-shadow:none}` stay in every touched `.dc.html`, including the page hosting the Retire reason Textarea and the booking-detail page hosting the Assign Select, since the kit paints `.vt-input--focus` with `--vt-ring`), no tinted yellow (no `--vt-yellow-50..300` backgrounds, no `Badge tone="warning"`, no `Alert tone="accent"`), four languages in the same pass, `CHF 000` placeholders, logical properties for RTL, native scrolling.

## Spacing Scale

The scale is the Vamos 4px token scale (`--vt-space-*` in `design-system/tokens/spacing.css`), not the generic 8-point list. `--vt-space-3` (12px) is a real kit token and is used on the signed screens, so it stays. Every value below is a multiple of 4.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-text gap, gap between name and badge when wrapped |
| sm | 8px | Gap between dialog checklist rows, button pair gap |
| md | 16px | Dialog body padding steps, Retired row padding, section gap inside dialogs |
| lg | 24px | Gap between the class table and the Retired section |
| xl | 32px | Not used by new elements (page rhythm owned by Pricing) |

12px (`--vt-space-3`) is used for the gap between the Retired head and its first row and between a Retired row's text block and its button when stacked.

Exceptions:
- The Draft badge button is 32px high as signed on sheet 1, so the row height does not change. The signed note left open whether it needs a 44px hit area with the same look; that is open question 5 (recommended yes) and is not in the contract until he answers.
- Dialog close `IconButton` is the kit `size="sm"`, which the bundle sets to 32px (`.vt-iconbtn--sm{width:32px;height:32px}`). The kit stays as is, not restyled. The 44px CANCEL / EDIT CLASS button next to it is the touch-safe path, and Escape and scrim click also close. A 44px hit area for the close X is open question 6.
- BRING BACK is the kit `size="sm"` (36px) at 1081px and wider, as sheet 4 draws it on a desktop pointer; at 1080px and narrower it is 44px (`size="md"`).
- Forbidden from the prototype: `padding:10px 16px` on the Retired head (off-scale), `max-width:78px` on the class cell.

## Typography

Four sizes, two weights. Badge 11px uppercase is kit-owned (`--vt-label-sm`) and the kit `.vt-btn--sm` 12px button label (BRING BACK at 1081px and wider) is kit-owned too; neither is counted as a page size.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Body | 16px (`--vt-body-md`) | 400 | 1.6 | Dialog body sentence, Retire reason input text |
| Label | 14px (`--vt-body-sm`) | 600 for names and item labels, 400 for sentences | 1.45 | Class name in a Retired row, checklist labels, reason text in a Retired row, why-line, error text |
| Small | 13px (`--vt-body-xs`) | 400 | 1.45 | Chauffeur retired flag, count in the Retired head, 0 / 140 counter |
| Heading | 20px (`--vt-heading-3`, Qurova) | 600 | 1.18 | Dialog titles only (kit `Dialog`) |

Why 13 and 14 both exist: they are the kit's own `--vt-body-xs` and `--vt-body-sm` steps. The kit Dialog subtitle (`.vt-dialog__sub`) and the existing OpsTable and chauffeur screen already use them, so the two sizes are inherited, not invented. Inventing a single merged size would restyle kit and existing text.

The Retired head reads 14px Poppins at weight 600 with the count at 13px 400, as sheets 1 and 4 draw it. Weight 500 is not used anywhere (the prototype used it in places; remove).

Button labels, badges, kickers: UPPERCASE through the kit (`--vt-label-sm` tracking). Everything else is sentence case.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F6F6F6` page ground, `--vt-bg-surface` white panels | Pricing page ground, table, dialog surface, Retired list |
| Secondary (30%) | Charcoal `#1E1F1F` | Ops sidebar, LIVE badge (`Badge tone="inverse"`), secondary buttons (EDIT CLASS, CANCEL; kit `secondary` renders charcoal, as on the signed sheets), BRING BACK, `--vt-border-subtle` hairlines |
| Accent (10%) | Yellow `#FDC20B` | See reserved list |
| Destructive / semantic | `--vt-danger` | Chauffeur "Retired class" flag, missing items in the Go live checklist, failed-action error text |
| Positive | `--vt-success` | Done items in the Go live checklist only |

Accent reserved for: ADD CLASS (existing primary), RETIRE confirm in the Retire dialog (primary), GO LIVE in the Go live dialog (primary, only while enabled). Nothing else is yellow, except the kit focus ring `--vt-ring` on focus-visible (allowed by the no-glow law): not badges, not the Draft badge, not icons, not the Retired list.

Rules:
- LIVE = `Badge tone="inverse"` (bundle: `background:var(--vt-charcoal-800); color:var(--vt-text-inverse)`). DRAFT = `Badge tone="outline"` (bundle: transparent, `border-color:var(--vt-border-subtle)`, `color:var(--vt-text-secondary)`).
- No RETIRED badge appears on any signed sheet (sheet 4 rows show name, reason, BRING BACK only), so none is built. For the record, the kit default `Badge tone="neutral"` maps to `background:var(--vt-grey-100); color:var(--vt-charcoal-700)` in `_ds_bundle.js` (Badge.jsx); it is not used in this phase.
- Retire is reversible, so it is not red: the row action is neutral charcoal. `--vt-danger` is never used on a Retire control. Red stays for the data problem (chauffeur flag, missing checklist item).
- No tinted panels for Draft or Retired rows. Row background is the table's own surface in all states. Retired rows use white with a `--vt-border-subtle` hairline.
- Disabled GO LIVE uses the kit disabled button style (grey, as on sheet 2; no opacity tricks, no custom grey).

## Copywriting Contract

All strings go in the page `T` tables and in `app/vamos-i18n-dict.js` in the same pass. Class names are Latin in every language (D-14a) and sit in `data-vt-no-i18n` with `unicode-bidi:isolate` in Arabic. Numbers and counts sit in `vt-dir-keep`. Strings with a number or a name are `patterns` entries or split nodes (`{{ value }}` splits a sentence into text nodes: translate the parts, wrap the value in `vt-dir-keep` + `data-vt-no-i18n`). German is Swiss ("ss", never "ß"). The Arabic word for chauffeur is the one the dictionary already uses (prototype: سائق); do not introduce a second term.

Label exceptions, recorded: CANCEL and RETIRE are owner-signed labels (sheet 3). They are exceptions to the generic or single-word label rule ("Cancel" and "Retire" as the whole label), kept because he signed them.

## States

Every element, every state. "Kit" means the kit component's own style, never restyled.

### Class row badge (Live and Draft, in the class cell)

| State | Spec |
|-------|------|
| Default Live | `Badge tone="inverse"` text "Live". Not interactive (no button). |
| Default Draft | `Badge tone="outline"` "Draft" inside the 32px button (as signed). |
| Hover (Draft) | Badge border steps to `--vt-border-strong`. No glow, no fill tint. |
| Press (Draft) | `translateY(1px)`. |
| Focus (Draft) | `--vt-ring` on the button, offset 2px, visible against the white cell. |
| Disabled | Not applicable (always openable). While Go live or Retire is saving for that row the button gets `aria-disabled="true"` and ignores clicks, same look as default. |
| Loading | While the class list loads, the cell shows the existing table skeleton row. No badge until data is in. |
| Empty | No classes: existing Pricing empty table. Nothing new. |
| Error | A failed load shows the existing Pricing error line. Badge never shows a guessed state. |

### Go live dialog

| State | Spec |
|-------|------|
| Default | Title "Before this class goes live", subtitle = class name. Four checklist rows (Photo, Seats, Bags, Price in the live price book). One why-line when something is missing, none when nothing is missing. EDIT CLASS secondary, GO LIVE primary. |
| Hover / press | Kit button states. |
| Focus | First focus on EDIT CLASS. `--vt-ring` on buttons and close X. |
| Disabled | GO LIVE is `disabled` while anything is missing. The why-line sits directly above the buttons so the reason is visible without hover. EDIT CLASS is always enabled and closes the dialog and opens the class editor. When nothing is missing there is no line and GO LIVE is enabled. |
| Loading | GO LIVE shows `loading` with "Going live…". Both buttons and close X are disabled until the request settles. |
| Empty | Not applicable (the list is always four rows). |

# Phase 06.1 Plan 01 — Dashboard instant sidebar navigation

## Objective

Remove the dashboard-only hash-route animation so an operations sidebar selection switches the existing `#dc-root` view immediately and in place. Preserve the existing ops-shell hash routing, desktop active-route behavior, narrow-drawer closure, and public-site cross-document transition behavior.

## Scope and guardrails

- Change only the canonical source and focused regression test listed in frontmatter.
- Do not edit generated `apps/web/public/app/vamos-page-transition.js`; the normal build/sync pipeline owns it.
- Do not modify `app/ops/ops.dc.html`: its existing `readHash()` and `hashchange` state update are the local-route implementation and must remain intact.
- Do not modify `app/ops/OpsSidebar.dc.html`: existing hash anchors and active-route behavior remain the navigation mechanism.
- Do not change the generic transition controller, boot cover, document-navigation interception, `eligible()` hash exclusions, public-site motion, data/API behavior, copy, layout, or breakpoints.
- Do not deploy, change public DNS, or touch live configuration.

## Tasks

### 1. Remove dashboard-only hash-switch motion

**Type:** implementation

**Files:** `app/vamos-page-transition.js`

**Action:**

1. Trace the dashboard-only block beginning with `isDashboardPage()`.
2. Remove `isDashboardPage()` if its only consumers are the removed block; otherwise leave only necessary non-motion code.
3. Remove `runDashboardHashTransition()`, its forced reflow, dynamic `vtOpsHashSwitch` style injection, and its `hashchange` listener.
4. Do not alter document-level overlay creation, boot-cover handling, page-navigation eligibility, or the generic click listener.

**Verify:**

- Search the canonical script for `vt-ops-hash-switch`, `vtOpsHashSwitch`, and `runDashboardHashTransition`; all must be absent.
- Inspect the unchanged generic hash-only navigation exclusion and public transition path.

**Acceptance criteria:**

- Dashboard hash changes have no authored opacity, transform, animation, transition class, overlay, or delay.
- The public document-transition controller remains intact.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (`apps/web` unit) · pgTAP (`packages/db`, local Supabase only) · Playwright (`apps/web` behaviour + visual) |
| **Config file** | `apps/web/vitest.config.ts` · `packages/db/supabase/tests/*.test.sql` · `apps/web/playwright.config.ts` |
| **Quick run command** | `pnpm --filter web exec vitest run <path>` (scoped) · `pnpm db:test` for pgTAP after `pnpm db:reset` |
| **Full suite command** | `pnpm test:unit` + `pnpm db:start && pnpm db:reset && pnpm db:test` + the CI gate order (`check:public-env`, `typecheck`, `lint:css`, `lint`, `i18n:check`, `check:legal-claims`, `check:numbers`, `build`) |
| **Estimated runtime** | ~60 s scoped · ~15 min full (pgTAP reset dominates) |

Local Supabase only. Never `db:push` / `db:link` against `yaumjzvylngfjhtuffqs`. New migrations are handed to the owner as SQL.

---

## Sampling Rate

- **After every task commit:** scoped vitest or pgTAP run for the touched module.
- **After every plan wave:** full `pnpm test:unit` + `pnpm db:reset && pnpm db:test`.
- **Before `/gsd-verify-work`:** full suite green, including the staff-MFA pgTAP assertions this phase turns green.
- **Max feedback latency:** 120 s for a scoped run.

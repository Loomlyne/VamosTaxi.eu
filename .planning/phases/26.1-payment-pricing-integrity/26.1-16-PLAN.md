<interfaces>
Open route refusals after 26.1-15: `{ ok: false, code: "pay_link_paid", reference }`, `pay_link_refunded_duplicate` (+ reference), `pay_link_expired`. Body accepts optional `session_id`.
A Checkout Session client secret starts with the session id followed by `_secret_`; derive the id client-side rather than adding a field.
`settlePaidReturn(env, sessionId)` → `"paid" | "unpaid" | "failed"`, calls `handleStripeMessage`, whose `HandleResult` is `{ ack: true } | { retry: true }`. This plan extends the ack with an optional `settled?: { duplicate: boolean; revived: boolean }` so the return route can see a duplicate.
Existing PayClient keys: `quoteExpired`, `quoteAlreadyBooked`, `paymentWindowClosed`, `pricingNotLive`, `completeCard`, `payCouldNotStart`. Kit: `Card`, `Alert`, `Icon` (`circle-check`). BookingVoucher's confirmed header is the shape reference for the paid card.
</interfaces>

files:
1. `create role … password :'vamos_edge_password'` cannot ship — the CLI does not expand psql

   password — fail-closed), and the password is set out-of-band per environment when Phase 3 wires
   Hyperdrive (documented in `packages/db/README.md` by Plan 02-01). No secret literal in the repo.

   `check_function_bodies` validates a SQL-language body at creation — the draft already applies
   this reasoning to `app.booking_has_manage_token`. Both functions therefore ship in

   `app.jwt()`, `app.uid()`, `app.manage_token_hash()` and the schema/role/default-privilege lines.

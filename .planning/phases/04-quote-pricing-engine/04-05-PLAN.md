<objective>
The database half of QUOTE-04 and QUOTE-05: a second clock the trigger can see, a board the dispute
packet can read, and an arithmetic identity the row itself refuses to break.

D-42 moved the snapshot INSERT to the booking transaction, which quietly broke Phase 2's own
QUOTE-04 proof: `tg_payment_matches_snapshot` reading `s.expires_at` now sees a payment window
written on the SAME insert, so it can never fail a held, expired token. This plan is where that is
repaired — `quote_lock_expires_at` is persisted and the gate reads it, so deleting the Worker's
expiry `if` genuinely changes nothing.

Purpose: after this plan, "an expired quote is refused server-side, not merely hidden in the UI"
is true of a `psql` session with no browser and no Worker in the picture at all.
Output: two additive migrations, two new pgTAP files, an extended charge-gate proof.
</objective>

same voice — with the payment-method radio group replaced by Stripe's own Element and two languages

executed deliberately rather than "ported faithfully".

research's Wave 0 gap list names.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → `/api/checkout/intent` | Everything the customer types crosses here; none of it is trusted |

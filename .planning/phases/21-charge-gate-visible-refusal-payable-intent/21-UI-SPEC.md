# Phase 21 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Canonical:** `21-CONTEXT.md` D-01…D-13 wins on conflict. Pixel-faithful to `app/pages/checkout.dc.html` pay chrome (live `PaymentPanel` / `.vt-checkout__cardfields`), `app/home/home.dc.html` fleet cards, and kit `Alert` / `Button` / `Input`. **No redesign. No new layout. Frozen chrome.** Leftovers 16/17/19/20 untouched.

This phase answers: *what does unpriced / expired / payable look and feel like on the surfaces that already exist?* It does not capture a card, wait on webhooks, paint wallets, split traveller/payer mail, Publish fares, or invent CHF.

Copy in this contract is English source. Ship **en / de / fr / ar** in the same sitting. Arabic `dir="rtl"` with logical CSS only. Swiss German, "ss" not "ß". Never assemble sentences around variables.

**Tool: none.** Do not initialize shadcn. `--vt-*` only.

## Locked product (D-01…D-13)

CONTEXT wins over ROADMAP wording. ROADMAP success criterion 1 says “Alert + requote” for unpriced — that is the **Pay backstop**, not a sentence on the class card.

| ID | Surface | Contract |

## Copywriting Contract

Verb-first. Sentence case matching DC / live `checkout.*` keys. No oops. No “Something went wrong”. No OK / Continue / Save / Cancel / Submit as the refusal action. Errors say the problem and the next step.

**Reuse first.** Do not write a second English sentence if `pricingNotLive` / `quoteExpired` / `requote` already match. New strings, if any, same sitting en/de/fr/ar. Never concatenate around variables.

Silent Select (D-01): **ZERO new card copy.** No tooltip. No “pricing not live” on the class card. `aria-disabled` + visible `CHF 000` is the signal.

| Element | Copy |
|---------|------|
| Primary CTA (this phase) | **Get a new quote** (`checkout.requote`) — checkout Pay only. Verb-first. Not on the token page. |
| Empty state heading | none this phase — unpriced is not empty |
| Empty state body | Cards stay. Every Select off. No “No data found”. No “no classes” illustration. |
| Error state (unpriced Pay / token) | `checkout.pricingNotLive` — problem + next step (call dispatch). |
| Error state (expired / lock-dead) | `checkout.quoteExpired` — problem + next step (get a new price). Checkout Pay adds the Requote control; token page is copy only (D-10). |

### H2 — Every class unpriced (D-02)

- Same cards, every Select off. Board stays. Quote shell stays. No empty-state illustration. No “no classes” heading. Continue does not enter Pay.

### P1 — Land on checkout Pay unpriced (D-03, D-05, D-06, D-07)

- Same skeleton as P1.
- `Alert tone="danger" role="alert"` + `quoteExpired` + Requote.

### P3 — Sit on priced Pay, lock hits zero (D-04)

- Refuse **now**. No refresh. No next tap. No new session.
- If Stripe was **not** mounted yet → become P2 (dummy fields).
- If Stripe **was** mounted → **leave the iframes in place**, make them unusable: `pointer-events: none`, fields visually disabled (cannot type), Express/Link if present becomes inert / `hidden`. Do not remount dummy Inputs over live iframes (that would create a new session or a flash).
- Same danger Alert + Requote as P2.
- Pay + Email a pay link disable immediately.
- **Live region:** the Alert must announce when it appears at zero without a reload. Override `role="note"` with `role="alert"` (assertive live). Prefer a stable Alert node whose text updates at zero over a one-shot insert that some SRs miss.

### P4 — Payable mahaha (success criterion 3)

- No refusal Alert.
- Live `PaymentPanel` (Custom Checkout `ui_mode: "elements"`). Card number / expiry / CVC / country as today.
- Pay enabled. Email a pay link enabled when payer email is valid (inherited).
- Amount is the **live lock figure**, never a made-up rappen. If the class is unpriced this state does not exist.
- UAT class is **mahaha** only. Do not Publish. Do not invent the rest of the sheet.

### T1 — Token land expired / unpriced / dead (D-06, D-10, D-11, D-12)

- Trip recap stays (pickup, dropoff, amount or `CHF 000`, reference if present).
- Alert on top (`pricingNotLive` info **or** `quoteExpired` danger). Not `paymentWindowClosed`. Not `payCouldNotStart`.
- Dummy dead fields. No Stripe. No session.
- **No Requote.** No Home button. No edit of the trip.
- Pay disabled if the CTA still exists; prefer keeping the disabled **Pay and continue** so the layout does not jump.

### T2 — Token payable

- Same recap + live `PaymentPanel` as today. Out of scope to restyle.

When the lock dies, **nobody** pays — checkout or token (D-12). Resend does not restart the clock (no UI that implies it does).

Job semantics (contract):
- support / support-form: read the message (form: resolve the inbound_form message id first); skip staff/note directions; translateUnknown(ai, { text, to: ["en","de","fr","ar"], fallbackLang: form_locale }); put rows: done for each translated target, rejected for each guard-rejected target; detected_lang stored; a target equal to the detected language is not written (reader treats it as "same").
- note: same with bookingNoteSource / putBookingNoteTranslation and the note_hash.
- review: reviewLanguageSource; skip unpublished or already-set; translateUnknown(ai, { text, to: [] }) (detect only); setReviewLanguage when lang matches ^[a-z]{2}$.
- extra: extraLabelsMissing filtered to the code; translateText(ai, { text: label_en, from: "en", to: missing }); fillExtraLabel(code, sql.json(out)).
- Transient failure (reason timeout, model_error) -> throw so the consumer retries with backoff; final failure (guard, parse, refusal, finish, too_long, empty) -> write rejected/failed rows and ack; no_binding -> ack without writing (left for the sweep).

Contract this plan CREATES (plan 32-11 codes against it):
  PublicReview gains `ref: string` (16 hex) and `language: string | null` (two letters).
  GET /api/reviews/:ref/translation?lang=xx
    200 { ok:true, data:{ text } }  cache-control `public, max-age=3600, s-maxage=86400`
    400 { ok:false, code:"bad-request" } (ref not ^[0-9a-f]{16}$ or lang not en/de/fr/ar)
    404 { ok:false, code:"not-found" } (no published review with that ref)
    409 { ok:false, code:"same-language" } (review language unknown or equal to lang)
    429 readRateLimited()
    503 { ok:false, code:"unavailable" } (model down, rejected, or attempt cap reached)
    every non-200: `private, no-store`; POST/PUT/PATCH/DELETE -> 405.

| T-32-33 | Information disclosure | review row ids / unpublished reviews | mitigate | opaque ref; review_translation_source resolves published rows only; tests assert no id and 404 for unpublished |

<objective>
Write the harness that turns the probe Worker into a decision: does request-scoped auth context
leak between requests sharing a pooled connection, or not — and can this suite tell?

The assertion is an adjacency set, not a row count. For every pair of probes on the same
`pg_backend_pid()` where one follows the other with nothing between them and the two ran as
different identities, the follower must have seen a clean session and its own rows. The size of
that set, `S`, is the real sample size; `N` is not. A run whose `S` falls below the floor is
INCONCLUSIVE and fails, and a run where the mutants come back green fails too.

**Nothing in this plan runs against a deployed anything.** Every file is skipped unless
`PROBE_BASE_URL` is set, so `pnpm typecheck` and the local Vitest sweep stay green on a machine
with no Cloudflare account. The execution is plan 03-07.

**Precondition:** plan 03-04's probe response shape and closed `impl` union — this harness is
written against them, not against a sketch.

**DATA-05's p50 is DEFERRED (D-23).** `hyperdrive-metrics.ts` contains the query; the number
comes from plan 03-07 or the phase summary carries the literal line
`DATA-05 p50 = DEFERRED (no staging Worker)`.

Purpose: a green isolation run that nobody can interrogate is theatre. This plan is the part
that makes the run interrogable — the floor, the validity gates, and the controls that are
demonstrated able to fail.
Output: a concurrency driver, a metrics reader, a config-precondition gate, and the three
deployed test files.
</objective>

<objective>
Prove DATA-06's Postgres half deterministically, on the local stack, and prove that the proof
itself can fail.

Four pgTAP files close the fail-closed, cross-claim, rollback and quote-identity claims. A connection-reuse
simulator pins one physical backend with `sql.reserve()` and replays customer A, then customer
B, then a bare entry probe **through the shipped `withIdentity`** — because the connection is
pinned, a residue bug fails 100% of the time, where Hyperdrive would only fail when the pool
happened to reuse. Two migration mutants and a gate script turn "the suite is green" into "the
suite is green **and** demonstrably goes red when the grant layer or the policy predicate is
broken".

**Precondition (D-30):** this plan is the first in Phase 3 that touches a live database. It
needs Phase 2 executed through **plan 02-05** (`public.bookings`, `booking_legs`,
`next_booking_reference()`) and **plan 02-08** (RLS enabled, the revoke-all baseline, and the
§14a customer policy `customer_id in (select c.id from public.customers c where c.user_id =
app.uid())`). `public.customers` and `public.staff` already exist (plan 02-03, migration
`…06_customers_and_staff.sql`). Do not stub a role, a grant or a policy to make a test go
green — if Phase 2 has not landed 02-05/02-08, this plan waits.

This plan also carries the executable half of the **Phase 3<->4 quote-identity seam** (D-44a):
`quote_identity.test.sql` proves the negative — the quote identity reaches no customer-scoped
table — and auto-detects the write path Phase 4 must add, so the seam is a live test rather than
a note somebody has to remember.

**This plan adds no migration (D-31).** Every `.sql` file it writes is a pgTAP test or a mutant
that `scripts/mutation-gate.mjs` applies and then restores.

Purpose: the ROADMAP's second success criterion names the pooled connection, and that half waits
on plan 03-07 — but the mechanism that makes it true is Postgres-side and provable now.
Output: four pgTAP files, three Vitest files, two mutants, one gate script.
</objective>

- `CheckoutSignIn({ email, onEmail(v), locale, returnTo, turnstileSiteKey, stage: "form"|"sent", onStage(s), onSignedIn(), payBlockError: string | null, disabled: boolean })`
  - form stage POSTs `/api/auth` JSON `{ locale, returnTo, method: "magic", mode: "signin", email, origin: "checkout", turnstileToken }` (credentials same-origin). Answers: 200 `{ stage: "sent" }` → sent; 429 → "Too many tries…" line; 400 `{ stage: "form", banner: "send_failed" }` or network error → `Alert tone="danger"` "The link did not send. Try again."
  - sent stage "SEND ANOTHER LINK" re-POSTs the same body (new Turnstile token); code "SIGN IN" POSTs `{ locale, mode: "verify-code", email, code }` (the shipped action) → `{ ok: true }` → `onSignedIn()`; `code-invalid` → field error; 429 → rate line.
  - "More ways to sign in" is a link to `/{locale}/sign-in?returnTo=<returnTo>` (the host passes an onClick stash; expose `onMoreWays?: () => void`).

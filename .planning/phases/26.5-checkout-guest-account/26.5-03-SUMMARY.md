# Phase 26.5 Plan 03: Checkout sign-in send Summary

Checkout gets its own enumeration-neutral sign-in-link send on `POST /api/auth` (`origin: "checkout"`): `createUser: false`, Turnstile action `account`, IP limiter plus per-address `auth-checkout:<email>` bucket, and a 1200 ms + 0-150 ms response floor. Helper `sendCheckoutSignInLink` / `CHECKOUT_SEND_FLOOR_MS` is exported for the PAY gate (plan 04).

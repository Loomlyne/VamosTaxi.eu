## 7. Things the visual spec assumes that need the right env

`guestAccountsOn` reads a database flag and `accountCreateAvailable` needs the service-role key name on the environment. In a plain `next dev` run without them both are false: the Create option is absent and the guest line (Text 2) does not show. To exercise the Create and guest cases, either set the local env so both return true, or route-fixture at the server level by a dev-only override; do not change the production code path for the test. Until that is decided, the create/guest tests in the spec will fail at the `[data-acct-option="create"]` click.

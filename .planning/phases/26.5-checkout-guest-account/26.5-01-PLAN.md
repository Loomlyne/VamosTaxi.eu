  `constraint account_agreement_records_surface_check check (surface in ('checkout','sign-up'))` (named so a later migration can

  `booking_id uuid references public.bookings(id) on delete set null` (nullable: sign-up rows have none),
  `email text not null` (checkout: copied from the booking; sign-up: the address the person typed),
  `choice text not null check (choice in ('create','guest'))`,
  `record_kind text not null check (record_kind in ('consent','informed'))`,
  `text_version text not null check (pg_catalog.btrim(text_version) <> '')`,
  `locale text not null check (locale in ('en','de','fr','ar'))`, `user_agent text`, `ip_truncated inet`,
  `recorded_at timestamptz not null default now()`,
  `constraint account_agreement_records_kind_check check ((choice = 'create' and record_kind = 'consent') or (choice = 'guest' and record_kind = 'informed'))`,

  No NOT NULL column that only checkout can fill; `text_version`, `locale` and `recorded_at` are NOT NULL for both surfaces.
  Indexes `(booking_id, recorded_at desc)` and `(pg_catalog.lower(email), recorded_at desc)`. Table comment: create = consent to Text 1

|----------|-------------|
| Worker (vamos_system) → Postgres | The settle queue asks the database to decide and record one Purchase |
| Worker (vamos_checkout) → Postgres | The Pay press stores a browser's consent subject with the two Meta ids |
| Consent ledger → claim | The latest consent choice decides whether anything may be sent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-01 | Tampering | meta_purchase_events | mitigate | PK on booking_id under the booking `for update` lock; row written before any send; no retry path re-inserts |
| T-29-02 | Elevation of privilege | claim/finish/clear_ids/writer | mitigate | security definer, `search_path=''`, EXECUTE vamos_system (claim, finish, clear_ids) / vamos_checkout (writer) only, revoked from public; pgTAP asserts |
| T-29-03 | Information disclosure | meta_purchase_events, meta_consent_subject | mitigate | forced RLS, no table grants, column not granted to authenticated/vamos_guest; table holds no personal data |

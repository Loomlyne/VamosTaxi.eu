<interfaces>
Keep ingestInboundEmail(env, payload): Promise of ok | drop | unavailable.

Algorithm:
1. token = tokenFromInboundTargets(payload.to, payload.receivedFor)
2. rfc ids = parseInboundHeaders(payload.headers) inReplyTo + references (and payload.messageId is the inbound's own id — store it on insert, do not match the inbound against itself)
3. body = inboundBody(payload) after 14-02 strip; if empty, body = Message could not be read.
4. asSystem TX:
   a. Find ticket: if token, SELECT contact_submissions where reply_token = token limit 1. Else if rfc ids, SELECT support_messages where rfc_message_id in ids limit 1 → submission_id. Never WHERE email = from.
   b. If no ticket: INSERT support_inbound_events on conflict do nothing; return drop.
   c. INSERT support_inbound_events; if conflict returning empty, return ok (D-12).
   d. INSERT support_messages direction inbound_email, body_text, from_address, rfc_message_id = asRfcMessageId(payload.messageId) when present, resend_email_id = emailId.
   e. UPDATE contact_submissions set ticket_status = inboundTicketStatus(current), last_activity_at = now(), closed_at = null.

Do not look up From. Do not create a new contact_submissions row. Do not set body_html. Do not call R2 in this plan. Files plan 14-05 will extend the TX.

If !token && no rfc ids: same as unmatched (drop + event). Do not require body to match — D-07.

Do not edit tickets-write.ts (Phase 13 other session). Do not edit OpsSupportTicket.dc.html.
</interfaces>

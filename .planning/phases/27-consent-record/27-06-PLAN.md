<interfaces>
Server contracts (plans 27-02, 27-05):
- GET /api/consent/state -> {ok:true, chosen:false, policyVersion} | {ok:true, chosen:true,
  policyVersion, choice:{method, functional, analytics, marketing, recordedAt}} | 503 {ok:false}.
- POST /api/consent JSON {method:"accept_all"|"reject_all"|"settings_change", locale,
  functional, analytics, marketing, turnstileToken?, idempotencyKey?} -> 200 {ok:true} |
  400 invalid_input | 403 challenge_failed (or CSRF) | 429 rate_limited | 503 unavailable.
  Turnstile token required iff the row will have marketing true.
Owner texts (plan 27-03): `window.VamosMetaTexts.segments('banner'|'cookiesRow'|'privacyLine', lang)`
returns an array of strings and {b:string} / {code:string} objects.
Mock dict strings (plan 27-03): 'Your choice was not saved. Try again.',
'The check did not go through. Try again.'; existing 'Cookie policy'.
Turnstile site key: `<meta name="vt-turnstile-site-key">` injected by middleware on every mock
(plan 27-04). Explicit render pattern: app/pages/contact.dc.html lines ~440-470.

VamosConsent API to create:
- state(): Promise resolving {ok:true, chosen, choice|null, policyVersion} or {ok:false} on network
  error / non-2xx. fetch('/api/consent/state', {cache:'no-store', credentials:'same-origin'}).
- save(method, cats, opts): Promise resolving {ok:true} or {ok:false, code}; posts JSON with
  locale from VamosLocale, cats {functional, analytics, marketing}, opts.turnstileToken,
  opts.idempotencyKey (crypto.randomUUID when available). On ok writes
  localStorage.vamosCookieConsent = {v: policyVersion, method, functional, analytics, marketing,
  at} (display cache only) and dispatches window event 'vamos:consent' with the choice.
- onChange(fn): subscribes to 'vamos:consent'; returns an unsubscribe function.
- cached(): the display cache only if its v equals the last known policyVersion, else null.
- turnstile(container, onToken, onError): lazily loads
  https://challenges.cloudflare.com/turnstile/v0/api.js?render=explicit once (reuse
  window.turnstile if present), renders with sitekey from the meta, action 'consent',
  appearance 'interaction-only', execution 'execute'; returns {execute, reset, remove}. If the
  meta is missing or empty, calls onError('no-site-key').
</interfaces>

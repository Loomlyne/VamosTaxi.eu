## Spacing Scale

Project token scale `--vt-space-*` (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs (`--vt-space-1`) | 4px | Icon-to-text gap inside the bar's second line, kicker-to-field gap |
| sm (`--vt-space-2`) | 8px | Header ↔ docked-bar gap, field ↔ its hint, progress ↔ header row, footer hint ↔ button |
| sm+ (`--vt-space-3`) | 12px | Bar inner gap (icon ↔ text), sheet footer block padding, date ↔ time column gap |
| md (`--vt-space-4`) | 16px | Sheet inline padding on phone, gap between blocks inside a step, bar inline padding |
| lg (`--vt-space-6`) | 24px | Sheet inline padding on tablet, step title ↔ first field |
| xl (`--vt-space-7`) | 32px | Space under the last block of a step before the footer |

Exceptions (fixed by `CLAUDE.md` / design system, not spacing tokens):
- Control heights: **54px** (`--vt-control-h-lg`) for the bar, every sheet field, and NEXT / SEE PRICES; **44px**
  (`--vt-control-h-md`) for Close, Back, steppers, the "Add a flight number" opener, ops fields and checkboxes.
- Sheet header row = 8px + 44px + 8px = 60px. Sheet content column `max-inline-size: 560px`, centred on tablet.
- Sheet footer: 12px block padding + 20px hint line + 8px + 54px button + `env(safe-area-inset-bottom)`.
- Docked bar top = the floating header's measured bottom edge (`getBoundingClientRect().bottom`) + 8px; never a
  hard-coded number (the header is `clamp(56px,7vw,68px)` tall at `top: clamp(8px,1.4vw,14px)`).
- Page gutter `clamp(20px,5vw,56px)`, container 1200px (unchanged).

- Accessible name: empty `Book a transfer`; otherwise `Edit trip: {line 1}, {line 2}`. `aria-haspopup="dialog"`,

  `<span data-tok>Free cancellation window</span>`) in 13px `--vt-text-inverse-muted`, `check` icon `currentColor`,

## S2 — Full-screen booking sheet (`BookingSheet.dc.html`, home ≤1080)

**Container:** `role="dialog"` `aria-modal="true"` `aria-labelledby` = the step title. `position:fixed; inset:0`,
`--vt-bg-surface`, no radius, no scrim (full-screen), `z-index:400` (above the header, same layer as existing
sheets). Height follows `window.visualViewport.height` (fallback `100dvh`) so the footer rides above the keyboard.
Enter: `translateY(16px)`→0 + fade, 320ms `--vt-ease-out`; exit 200ms `--vt-ease-in`. Reduced motion: instant.
Layout: header (fixed) · body (scrolls, `data-lenis-prevent`, `overscroll-behavior:contain`) · footer (fixed).

**Header** (60px, hairline bottom), inline padding 8px:
- inline-start: **Back** `IconButton chevron-left` (mirrors in RTL), aria `Previous step`. On step 1 it is not
  rendered but its 44px slot is kept, so the title never shifts.
- centre: nothing (title lives in the body so German/Arabic titles can wrap).
- inline-end: **Close** `IconButton x`, aria `Close booking`.
- Under the row (8px gap, inline padding 16/24): `ProgressIndicator segments={4} value={step} size="sm"` with
  `valueLabel="1 of 4"` (13px, `.vt-dir-keep`) and `aria-label="Step 1 of 4"`, `aria-valuetext="Step 1 of 4, From"`.

**Body** (inline padding 16px phone / 24px tablet, content column max 560px, 24px top):
- Step title — Heading 20px, `tabindex="-1"`: `From` · `To` · `When` · `Travellers` (the box kickers, sentence case).
- Recap line under the title from step 2 on (13/400 secondary, ellipsis): step 2 `From Zurich Airport`; steps 3–4
  `Zurich Airport` + `arrow-right` + `Bahnhofstrasse 1`; step 4 adds `· Tue 29 Sept, 08:15`. Plain text, not a control.
- Step content (below).

**Footer** (hairline top, `--vt-bg-surface`, inline padding 16/24, block padding 12px, `+ env(safe-area-inset-bottom)`):
- One hint line (13/400, `--vt-text-secondary`, max 2 lines) — replaced in place by the **warning** when the step is
  incomplete (D-04): `circle-alert` 16px + text, both `--vt-danger`. The line has `id` and `aria-live="polite"`; the
  failing field gets `aria-invalid="true"` + `aria-describedby` → this line and a `--vt-danger` border. The message
  is shown **once**, in the footer, not repeated under the field.
- 8px, then the step button, 54px, block: `NEXT` + `iconEnd="arrow-right"` (mirrors) on steps 1–3; `SEE PRICES` +
  `arrow-right` on step 4. **Never disabled.** Press on an incomplete step: warning replaces the hint, focus moves to
  the first failing field, nothing advances. The warning clears as soon as that field becomes valid (hint returns).

### Sheet mechanics **[discretion]**

- **Open:** from a user tap. Body scroll locked with `overflow:hidden` on `<html>` and `<body>` (the Lenis boot's
  lock observer stops the instance; if the pending "remove Lenis" quick task has landed, the same lock is simply
  native). Page scroll position is restored exactly on close. Never a second Lenis instance.
- **Focus:** on open and on each step change, focus goes to the step's address field (steps 1–2, from inside the tap
  handler so iOS raises the keyboard) or the step title (steps 3–4). Tab / Shift+Tab are trapped inside the sheet.
  `Escape` = Close. On close, focus returns to the bar that opened it.
- **Announcements:** each step change announces `Step 2 of 4, To` in a polite live region.
- **History:** opening pushes one entry (`history.state.vtSheet = step`, same URL); each NEXT pushes one more.
  Browser back / Android back / iOS edge swipe = previous step; back on step 1 = close. Back (header) = the same as
  browser back. Close = `history.go(-n)` to the entry before the sheet, so Forward never reopens it. A `popstate` that
  arrives with no sheet open is ignored.
- **Keyboard / safe area:** footer and body sized from `visualViewport` (`resize` + `scroll` listeners) on iOS and
  Android, so NEXT stays visible above the keyboard and the focused field is scrolled into view within the body.
  Inputs are 16px (no iOS zoom). Header gets `padding-top: env(safe-area-inset-top)`; footer gets the bottom inset.
- **Close keeps entries (D-02):** the trip state lives in `home.dc.html` memory for as long as the page is open — the
  bar shows it filled/partial and reopening continues from it. A reload, leaving home, or `SEE PRICES` starts empty
  (26.3 D-05: home never resumes). **Owner to confirm** "tab session" means "while the page is open", not
  `sessionStorage` surviving a reload.
- **Back from checkout** (`pageshow`, bfcache): sheet closed, bar empty.

## Accessibility and Motion

- Tap targets ≥44px; bar, sheet fields and the step button 54px. Visible focus everywhere (ring on controls,
  charcoal border on fields).
- Sheet: `role="dialog"`, `aria-modal="true"`, labelled by the step title, focus trapped, Escape closes, focus returns
  to the opener. Background content gets `inert` while open.
- Errors: `aria-invalid` + `aria-describedby` to the footer warning; one polite live region per sheet.
- `ProgressIndicator`: `role="progressbar"` with `aria-valuenow={step}`, `aria-valuemax=4`, `aria-valuetext`.
- Motion: 80ms press · 140ms hover/focus and field reveal · 200ms docked bar and sheet exit · 320ms sheet entrance;
  `--vt-ease-standard` / `--vt-ease-out`; nothing scales, springs or loops. `prefers-reduced-motion` → instant.
- Step changes do not slide horizontally (no carousel); the body content swaps with a 140ms fade.

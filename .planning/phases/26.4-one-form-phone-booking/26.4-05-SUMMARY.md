# Phase 26.4 Plan 05: BookingSheet Summary

Full-screen four-step BookingSheet (From + flight, To, When, Travellers) with progress, never-disabled NEXT / SEE PRICES, footer warnings, D-09 flight rule, history cleanup, focus trap, Lenis-safe scroll lock and visualViewport sizing; 19-state gallery and a 36-test spec.

- b4833fde: states gallery + spec (task 3)

## Contract (for 26.4-09)
Props: `open`, `step`, `inline`, `showIssues`, `fromText`, `fromHits`, `fromChosen`, `fromAirport`, `toText`, `toHits`, `toChosen`, `samePlace`, `flight`, `flightOpen`, `flightValid`, `date`, `time`, `minDate`, `whenError`, `whenLabel`, `pax`, `bags`. Callbacks: `onFromInput/onFromPick/onFromClear`, `onToInput/onToPick/onToClear`, `onFlight`, `onFlightOpen`, `onDate`, `onTime`, `onPax`, `onBags`, `onStep`, `onClose`, `onSubmit`. Hits may carry an optional `icon` (e.g. `plane-landing`); default `map-pin`. Host passes `whenError` in English (the runtime translates it; `Choose a time at least 3 hours from now` already exists).
Host duties: `onStep(n)` must set `step`; `onClose` must set `open=false`; `onSubmit` is called after the sheet has removed its history entries, so it can `location.assign` directly.

## Dictionary
Strings added under `/* 26.4 BookingSheet */`: pickup/drop-off list warnings, date warnings, three footer hints, Add a flight number, Optional, It does not change the price., Optional. It does not change the price. (for plan 08), Close booking, Previous step, Next, Time. Patterns: `^(\d) of 4$`, `^Step (\d) of 4$`, four `^Step (\d) of 4, <Title>$`, generic `^Step (\d) of 4, (.+)$`, `^From (.+)$`. Existing entries reused (See prices, From/To/When/Travellers, Passengers, Bags, Date, Flight number, Clear, warnings). No "ß".

## Deviations
1. [Plan] Tasks 1 and 2 (layout and mechanics) live in one file and were written together, so one commit covers both.
2. [Rule 1 - layout] Recap line wraps instead of ellipsis (UI-SPEC says ellipsis); at 390 both places were cut to unreadable stubs.
3. [Rule 1 - layout] Date/time: native glyph stretched invisibly over the field and padding tightened; the year was clipped at half width.
4. [Rule 1 - i18n] Progress value label is not forced LTR (it made Arabic read "من 4 3").
5. Sheet also sets `inert` on every sibling along its ancestor chain while open (UI-SPEC accessibility line), restored on close.

## Known limits
- visualViewport keyboard sizing, iOS focus-in-tap and real Android/iOS back gestures are not exercisable in headless Chromium; the code paths are in place but unproven on device.
- Opening at a step above 1 (host reopening mid-trip) is handled by treating that step as the history base; a SEE PRICES failure that points below that base uses `replaceState` instead of `history.go`.
- Arabic native date/time picker digits follow the device locale; not checkable here (owner decision asked for a check at 390 in Arabic on the phone).
- Home wiring is plan 26.4-09.

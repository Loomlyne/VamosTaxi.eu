## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-110 | Denial of Service | a dead database taking the home page down | mitigate | Both reads are wrapped and yield the sections' designed `error` states; plan 05-18's integration spec already proves a 200 with a dead binding, and this page's try/catch is what makes that true at the page level |
| T-05-111 | Information Disclosure | an authenticated read on a cacheable path | mitigate | The page reads only `publicSql`'s two content tables; it reads no session (the header's snapshot route is separate and `no-store`), so nothing identity-bearing is on this page's response |
| T-05-112 | Spoofing | a hand-rolled header or footer on the site's front door | mitigate | The layout composes `SiteShell(SiteHeader, SiteFooter)`; this page imports neither, and the spec asserts exactly one `header` and one `footer` |
| T-05-113 | Information Disclosure | a price appearing before the matrix lands | mitigate | Grep-asserted absence of `formatAmount`/`CHF`/`pricing_live`, plus a rendered-text assertion that no `CHF` string appears |
| T-05-114 | Tampering | content-strings XSS on the front door | mitigate | All values render as React text children (plan 05-18); no `dangerouslySetInnerHTML` anywhere under `components/home/**` or this page |
| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |

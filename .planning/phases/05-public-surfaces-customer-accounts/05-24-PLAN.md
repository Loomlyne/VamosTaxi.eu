<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard -> repository | Credentials cross from a human's screen toward a codebase |
| Supabase infrastructure -> staging Worker | A third party calls a public endpoint on our origin |
| staging Worker -> owner's inbox | Real mail is sent to a real person for the first time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-127 | Information Disclosure | a credential committed to the repository | mitigate | Every secret goes through `wrangler secret put`; the record stores names and dates only; an automated `git diff` pattern check for `eyJ|whsec_|re_|0x4AAAA` fails the task outright |
| T-05-128 | Spoofing | the Send Email Hook endpoint being reachable before its secret is set | mitigate | Plan 05-12's route returns 500 with no body when `SEND_EMAIL_HOOK_SECRET` is absent and 401 on an invalid signature, so registering the hook is the only way to make it functional |
| T-05-129 | Elevation of Privilege | email confirmation silently off in production | mitigate | D-28's toggle is read and recorded BEFORE being changed, and the committed `auth-confirm-email.spec.ts` fails if the behaviour regresses — a dashboard flip is reversible, a red test is visible |
| T-05-130 | Denial of Service | hook timeout on a cold Worker | mitigate | Check A times the real round trip against the dashboard's stated timeout; a failure escalates the DNS/zone blocker rather than being absorbed as an application change |
| T-05-131 | Denial of Service | a live form with no working challenge | mitigate | Check B exercises both forms against the live key pair before the phase is called done, and provisions a second pair if per-action reporting requires it |
| T-05-132 | Information Disclosure | a real submission echoed in a response | mitigate | Check C explicitly inspects the live response bodies, re-confirming plan 05-13's contract against real traffic rather than only against stubs |
| T-05-133 | Repudiation | an owner decision assumed rather than asked | mitigate | Four items each plan deliberately left open are put to the owner here with the reasoning that produced them, and the answers are recorded |
| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |
</threat_model>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-84 | Denial of Service | form spam | mitigate | D-22's always-on widget with `action="contact"`; the server is the verifier (plan 05-13) and no client path can fabricate a passing token — a grep asserts the widget never calls `onToken` with a literal |
| T-05-85 | Information Disclosure | the site key or secret in the client bundle | mitigate | The site key arrives as a server-rendered prop; no `NEXT_PUBLIC_TURNSTILE*` identifier exists; `scripts/public-env-allowlist.json` `allowed` stays `[]` and `forbidden_substrings` already covers `TURNSTILE_SECRET` |
| T-05-86 | Tampering | third-party script injection | mitigate | Only Cloudflare's documented Turnstile script URL is loaded, once, guarded; no other third-party script is added by this page |
| T-05-87 | Information Disclosure | server error detail rendered to the visitor | mitigate | The route returns a `code`; the form maps it to a translated message and a grep asserts the code itself is never rendered |
| T-05-88 | Spoofing | a stale or replayed submission | mitigate | A per-instance `idempotencyKey`, regenerated after a successful send, so a retry is collapsed server-side and a genuinely new message is not |
| T-05-89 | Repudiation | consent captured cookie-only | accept | This page captures no consent; D-20 puts SITE-08's server-side `consent_log` write in Phase 10, where the banner that promises it is built |
| T-05-SC | Tampering | package installs | mitigate | This plan installs no package; Turnstile is loaded as Cloudflare's own script tag, not an npm wrapper |
</threat_model>

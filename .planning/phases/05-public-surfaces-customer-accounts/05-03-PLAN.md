<objective>
Land, before any port starts, the two things every later Phase 5 plan depends on and neither
can safely own: the phase's complete four-language message key set, and the mechanism I18N-08
actually asks for — a page that exists in fewer than four languages saying so.

Phase 1 migrated the whole mock dictionary (1 516 keys x 4 locales, with `$meta`'s pending /
non-translatable / no-param lists). The realistic gap this plan closes is therefore small and
specific: strings the React ports need that no `.dc.html` string produced — the coverage
notice, the auth email subjects and bodies, the signed-in header's account menu, form status
copy — plus anything the scripted audit finds missing.

Concentrating those edits here mirrors Phase 4, where a single plan (04-08) owned every
message-file change for the whole phase, so no two parallel plans ever met in `en.json`.

Purpose: a port that stops halfway to invent a German string is a port that ships an English
flash. Output: complete message files, `LEGAL_LANGUAGES`, `LanguageCoverageNotice`, a states
gallery and its four-viewport baselines.
</objective>

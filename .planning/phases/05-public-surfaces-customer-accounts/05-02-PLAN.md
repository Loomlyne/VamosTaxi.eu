<objective>
Close the schema gap Phase 2 left open on purpose: `customers.user_id` is nullable and
unique-indexed, `customers.email` is `citext` unique-where-not-erased, and nothing creates or
links a `customers` row when someone signs up through Supabase Auth. This plan writes that
trigger.

It is the only Phase 5 plan that applies a migration in Wave 1. Migrations reach one shared
local Postgres through `supabase db reset`; two plans applying migrations in the same wave
would race the same database, so plan 05-08's `contact_submissions`/`partner_applications`
migration is deliberately held to Wave 2 behind this one.

Purpose: every RLS policy Phase 2 shipped that joins through `customers.user_id` is inert
until this trigger exists. AUTH-01 is not "an account was created" — it is "an account was
created AND the row every later customer-scoped read depends on exists".
Output: one additive migration, one pgTAP suite, regenerated types.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GoTrue -> public schema | A `security definer` function crosses the privilege boundary Phase 2 built |
| attacker signup -> existing customer row | An attacker-chosen email meets a row that may already hold a stranger's bookings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06 | Elevation of Privilege | `tg_link_customer_on_signup` `on conflict` branch | mitigate | `where public.customers.user_id is null` makes re-targeting an already-linked row impossible; pgTAP case 6 proves it and the mutation check proves the assertion can go red |
| T-05-07 | Spoofing | signing up as a victim whose guest booking exists | mitigate | Linking only becomes usable once the session is usable, which D-06/plan 05-24 gate behind email confirmation; the trigger itself grants no read — Phase 2's `customers_select_own` still requires a verified JWT |

| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |

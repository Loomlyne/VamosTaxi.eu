<objective>
Port `AuthForm.dc.html` (398 lines) and `ResetForm.dc.html` (204 lines) as presentation-only
React components with every state the mocks define, so plan 05-16 can wire real Supabase calls
to a component whose behaviour is already proven in four languages at four widths.

Splitting the component from its routes is deliberate. The mock's state machine has three modes
x two methods x four stages x three banner values, and most of those combinations are
unreachable from a happy-path integration test. A states gallery reaches all of them; a sign-in
page reaches four.

Three scope decisions are recorded here rather than made silently mid-port: the passkey
affordance is not ported (no requirement, no `@supabase/ssr` API, same reasoning as D-19's
PhoneVerify deferral), the `surface="ops"` branch belongs to Phase 6, and the signup
email-enumeration tradeoff 05-CONTEXT leaves to Claude's discretion is resolved toward the
non-distinguishing response with the mock's distinguishing banner still built and reachable.

Purpose: AUTH-01 and AUTH-02 are state machines before they are network calls.
Output: `components/auth/*`, a full states gallery and its baselines.
</objective>

  type AuthMode   = "signin" | "signup" | "forgot"
  type AuthMethod = "password" | "magic"
  type AuthStage  = "form" | "sent"
  type AuthBanner = "credentials" | "registered" | null
  isVerifiedPath(mode: AuthMode, method: AuthMethod): boolean   // D-06, derived not settable

  type AuthSubmitPayload =
    | { mode: "signin"; method: "password"; email: string; password: string }
    | { mode: "signin"; method: "magic";    email: string }
    | { mode: "signup"; method: "password"; email: string; password: string; firstName: string; lastName: string }
    | { mode: "signup"; method: "magic";    email: string; firstName: string; lastName: string }
    | { mode: "forgot"; email: string }

  type AuthFormProps = {
    mode: AuthMode; method: AuthMethod; stage: AuthStage; banner: AuthBanner
    pending?: boolean
    fieldErrors?: Partial<Record<"email" | "password" | "firstName" | "lastName", string>>
    onModeChange(m: AuthMode): void
    onMethodChange(m: AuthMethod): void
    onSubmit(payload: AuthSubmitPayload): void
    onResend?(): void
  }

  type ResetFormProps = {
    stage: "form" | "saved" | "expired"
    email: string
    pending?: boolean
    fieldErrors?: Partial<Record<"password" | "confirm", string>>
    onSubmit(password: string): void
  }

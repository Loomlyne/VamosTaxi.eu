<objective>
Build the shell all five legal pages share, then render the first one through it.

`terms`, `privacy`, `cookies` and `cancellation` are 380–445 lines of the same layout in the
mocks: a charcoal hero with a kicker, title, standfirst and a meta row (last updated, version,
languages, print), then a two-column grid of a sticky numbered section index and a 68ch prose
column, with `data-slot` TBC blocks, charcoal `data-flag` callouts and a print stylesheet.
Porting that layout four times is four chances to drift; porting it once is what makes plans
05-09 and 05-10 additions of content rather than repeats of structure.

Purpose: SITE-05 asks for five pages that render with real numbers where the owner supplied
them and labelled TBC pills where not. The pill mechanism and the print path are the parts
that are easy to lose in a port, so they are built first and proven once.
Output: `components/legal/{LegalPage,LegalToc,PendingSlot}`, `/terms`, four-viewport baselines.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| message catalogue -> rendered prose | Legal text is the highest-consequence copy on the site |
| URL fragment -> TOC scroll target | An attacker-supplied `#hash` reaches the anchor handler |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-15 | Tampering | prose rendered from message keys | mitigate | Every string is rendered as a React text child (auto-escaped). No `dangerouslySetInnerHTML` anywhere under `components/legal/**` — asserted by grep in the acceptance criteria of plan 05-23's sweep |
| T-05-16 | Repudiation | a legal page that silently under-declares its languages | mitigate | `LanguageCoverageNotice` is wired into the shell in this plan, so plans 05-09/05-10 inherit it structurally rather than remembering it |
| T-05-17 | Spoofing | breadcrumb / TOC links | mitigate | Every link is a next-intl navigation helper against a closed route set; the TOC's `href` is always `#${section.id}` from a typed literal list, never a request-derived value |
| T-05-18 | Information Disclosure | an invented effective date or version | mitigate | `PendingSlot` renders the English `$meta.pendingValueKeys` literal with the TBC treatment; Law 04 forbids substituting a number the owner has not supplied |
| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |
</threat_model>

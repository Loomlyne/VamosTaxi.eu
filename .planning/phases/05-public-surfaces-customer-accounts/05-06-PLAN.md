## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-23 | Tampering | `booking-draft` values reaching a later quote | accept | The draft is convenience state only; Phase 4's `/api/quote` is server-authoritative and re-validates every field with zod. Nothing in this plan trusts the draft for anything but repopulating its own inputs |
| T-05-24 | Spoofing | the mount seam | mitigate | `BookingCardMount` takes `ReactNode` props from its own parent only — there is no runtime registry, no dynamic import by name and no way for a third party to supply a board |

| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |

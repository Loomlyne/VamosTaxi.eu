## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| database content -> rendered page | Content editable from the ops console (Phase 6) renders on the public home page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-90 | Tampering | XSS through content-strings rendering | mitigate | Every value renders as a React text child; `dangerouslySetInnerHTML` appears nowhere under `components/home/**` or `lib/db/content.ts`, so a malicious string stored by a future ops editor renders inert |
| T-05-91 | Information Disclosure | an authenticated read served from the cacheable binding | mitigate | `content.ts` uses `publicSql` only, touches only two of the five allow-listed tables, and carries no identity claim; a grep asserts no identity wrapper is imported |
| T-05-92 | Information Disclosure | an unpublished or draft review going live | mitigate | `where published` plus Phase 2's `reviews_public_read` policy (`using (published)`); the integration spec inserts an unpublished row and asserts it does not render |
| T-05-93 | Tampering | SQL injection through a key list | mitigate | `where key = any($1)` with a bound array; no `like` interpolation, no `sql.unsafe(`, asserted by grep |
| T-05-94 | Denial of Service | database unreachable taking the home page down | mitigate | Both sections have a designed `error` state; the integration spec proves the page still returns 200 with a dead binding |
| T-05-95 | Denial of Service | leaked timers or observers in the carousel | mitigate | Every interval and observer is cleared on unmount, autoplay pauses off-screen and on focus, and is disabled entirely under reduced motion |
| T-05-96 | Information Disclosure | a pending value rendered as a stated fact | mitigate | `pending_value` rows always return the English column and wear the TBC treatment (ADR-011), never a translated or substituted value |
| T-05-SC | Tampering | package installs | mitigate | This plan installs no package. |
</threat_model>

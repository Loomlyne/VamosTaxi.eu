<interfaces>
Existing interfaces to retain:

  POST /api/auth
    action: signout | update-password | update-profile |
            passkey-start | passkey-verify |
            passkey-register-start | passkey-register-verify
  PATCH /api/staff/profile
    { fullName, phone, lang, digestEmail, avatarPath }
  POST /api/photos/upload
    multipart form file + kind=staff

New narrow interfaces:

  POST /api/staff/claim-invite
    authenticated active invited user only; stamps that caller's accepted_at once,
    refreshes the session, returns { ok: true }. No role, active, or other-user write.

  worker scheduled event
    Cron invokes hourly. It sends only when Intl Europe/Zurich is exactly 06:00.
    A unique (staff_user_id, digest_date) ledger row is claimed before any provider call.

Payment settings are capability/copy configuration only. They do not create Stripe links,
charges, Stripe Connect accounts, or any live payment method before Phase 7 / Phase 11.
</interfaces>

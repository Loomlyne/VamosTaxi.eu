## Database notes (words only, no migration written)

- **B1, remainder.** The Worker fix closes an already open Stripe payment page. It does not close a sent pay link: `checkout_pay_link_by_hash`, `checkout_pay_link_state` and `checkout_pay_link_lines` (20260928140000, 20260930170000) select on `status in ('pending','quote')` and never on `erased_at`, so the customer can open the link again and get a new payment page for an erased booking until the 24 hour hold ends. `checkout_payment_settle` (20260930100000) also confirms an erased booking. A full fix is a new migration that adds `and b.erased_at is null` to the three pay-link functions (and decides what settle does with a payment for an erased booking: today it would confirm it). That is a database change and a behaviour choice, so it is not done here.

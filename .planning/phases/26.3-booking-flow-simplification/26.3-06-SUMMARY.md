# Phase 26.3 Plan 06: Stripe hosted session layer Summary

Hosted Checkout session builder (card plus optional TWINT, Link off, no promo codes, 31-minute life, ar locale with a single en fallback) and presentment-currency capture on settle.

## Commits
- 3824cdfa feat(26.3-06): hosted session builder, method set, locale retry, payability helpers
- 3cfa5620 feat(26.3-06): settle stores presentment currency (and wrangler JSON fix)

## What changed
- `CHECKOUT_UI_MODE` removed. `uiMode` input defaults to `elements` (intent and pay-link routes still compile until plans 10 and 18); ops extra fare passes `elements` explicitly.
- Hosted: `ui_mode hosted_page`, `success_url` (must carry `session_id={CHECKOUT_SESSION_ID}`, http(s) only), `cancel_url`, `payment_method_types` `["card"]` or `["card","twint"]`, `wallet_options.link.display never`, `payment_intent_data.metadata.quote_id`, adaptive pricing on, no `allow_promotion_codes`.
- `checkoutPaymentMethodTypes(env)` reads `STRIPE_CHECKOUT_TWINT` (declared in env.d.ts, `"off"` in both wrangler blocks).
- `ar` is sent; a `StripeInvalidRequestError` on param `locale` triggers one retry with `en`, same idempotency key. Other errors rethrow.
- `allSessionsExpiredUnpaid`, `hostedSessionIsPayable` added; `sessionIsPayable` kept.
- `fxFromSession` reads `presentment_details` (CHF presentment gives nulls), falls back to `currency_conversion` (currency null there).
- `settle.ts` passes `fx.presentmentCurrency` as trailing arg of `checkout_payment_settle` (extra settle unchanged).

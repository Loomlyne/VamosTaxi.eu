# Phase 26.3 Plan 04: Home booking box Summary

The home box on `/` is now one layout at every width: From, Flight (only when the picked pickup is an airport), To, When, Travellers, SEE PRICES. It never shows a price, never writes `vamosTrip`, never calls a quote or abandon endpoint, and hands the trip to `/{locale}/checkout?...` in the URL.

## Commits

- `0851468b` feat(26.3-04): home booking box is From, Flight, To, When, Travellers, SEE PRICES with URL hand-off
- `0e918ce3` test(26.3-04): home booking box strings in four languages and spec; retire price-on-home specs

## What changed

- **Markup**: one box replaces the compact inline block plus the sheet/shell duplicate. Trip tabs, mode note, class strip, fixed-route picker and destination cards are gone. Layout is a 2-column grid at 681 and up (From, swap, To / Flight under From / When, Travellers / SEE PRICES / trust line) and one column at 680 and below, same DOM order. Fields are 54px, no glow, logical properties only.
- **Airport**: a picked pickup calls `/api/geo/retrieve` and uses `place.isAirport`; the name regex stays as the hint until retrieve answers (and if it fails). Swap re-checks the new pickup. Flight field fades in (140ms, none under reduced motion), upper-cases and single-spaces its value, is required, and is emptied when the pickup stops being an airport.
- **Travellers**: one 54px button "2 passengers · 3 bags"; popover at 681 and up, bottom sheet at 680 and below; 44px steppers (Passengers 1-8, Bags 0-16); Done, Escape, scrim; focus returns to the button.
- **SEE PRICES**: always enabled. Gaps show inline errors, focus goes to the first one in DOM order. Valid: `location.assign` to the contract URL, params in the order `from, fid, gs, to, tid, when, pax, bags[, flight]`.
- **Removed logic**: `fireQuote` (q is now a no-op), `saveTrip`, `readTrip`, `goTripOpen`, `phoneToTrip`, `pick`, `goFixedDest`, `beginHomeBooking` (abandon call), fleet loading, mode/fixed-route methods, the `#fleet` restore. `cleanStaleTrip()` removes `vamosTrip` and `vamosQuoteLock` (local and session) once on load.
- **Strings**: 21 dictionary entries plus four travellers-summary patterns, en/de/fr/ar (Swiss German "ss").

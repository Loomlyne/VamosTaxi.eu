# 26.3-G8 Plan: staff pay-link, Take card and extra-fare payment on Stripe's hosted page

Owner decision D-48 (26.3-CONTEXT.md): no card form of our own anywhere, the ops dashboard included.
Found by the Opus review after G7: `sessionIsPayable` needs a `client_secret`, hosted sessions have none, so
`staffPayLink` answered 409 `session-expired` for every booking made by the site flow and by New trip.

## Objective

1. Send pay-link (staff): mint the token, e-mail `/checkout/pay/<token>`; the customer's `pay-link/open` makes or reuses the hosted session. Payable check is `hostedSessionIsPayable`.
2. Take card (staff): `POST /api/staff/bookings/:id/take-card` returns the Stripe hosted URL (reuse the open hosted session, else create one through the same builder as pay-link open); the dashboard opens it in a new tab. The dashboard's Elements mount is removed.
3. Extra-fare payment: `acceptPaidEdit` creates a hosted `kind=extra` session; the dashboard offers Open Stripe payment page and Copy payment link through `POST /api/staff/bookings/:id/extra-pay`. Settle (webhook and `/api/checkout/return`) is unchanged.
4. Remove `ui_mode: "elements"`, `sessionIsPayable`, and the Stripe/Link CSP hosts and `js.stripe.com` script if nothing else needs them.
5. LOW items: `pay-link-gate.test.ts` asserts `intent/route.ts` passes `legacyUaeAccount: stripeAccountIsLegacyUaeTest(`; delete `runPayLinkIntent` / `mode: "pay_link"` and move the still-relevant tests; drop `checkout.emailFailed` (4 locales, seed, test).

## Acceptance

- staffPayLink and take-card answer OK for a hosted session with no client_secret; refusals kept (frozen, paid, test, no e-mail, expired quote).
- Extra-fare session is `hosted_page`, metadata `kind=extra`, no `payment_intent_data.quote_id`; success goes through the return route, Back to the ops booking.
- No `js.stripe.com`, no Elements, no client secret in the dashboard or lib; labels in en/de/fr/ar; no sideways scroll at 1440/1024/768/390.
- `pnpm --filter web build` (with lint), `tsc` 0 errors, full vitest, `i18n:check`, `db:seed:check` green.

## Threat model

| ID | Threat | Disposition | Mitigation |
|----|--------|-------------|------------|
| G8-01 | Take card charges a stale amount | mitigate | Amount is the booking's price snapshot total; reused session must pass `hostedSessionIsPayable` (open, url, CHF, amount equal) |
| G8-02 | Staff URL used for a paid, cancelled, test or expired booking | mitigate | Same loader refusals as pay-link (frozen, already-paid, is-test), snapshot expiry checked before Stripe |
| G8-03 | extra-pay leaks another booking's session | mitigate | Session must be open, `metadata.kind=extra` and `metadata.booking_id` equal to the resolved booking |
| G8-04 | New staff routes reachable without staff auth or CSRF | mitigate | `withStaff` wrapper (origin allowlist, MFA), POST only |
| G8-05 | Back/return URLs reflect input | mitigate | Staff origin is the allowlisted request Origin; return URL is the fixed settle route |
| G8-06 | Removing CSP hosts breaks a Stripe surface | accept | No page of ours loads Stripe.js or frames Stripe; card entry is a top-level navigation to checkout.stripe.com |

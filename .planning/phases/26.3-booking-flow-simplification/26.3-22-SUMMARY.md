## Bug found and fixed (Rule 1)

`fxFromSession` (26.3-06) returned `fxSource` and `presentmentAmountMinor` but null `fxRate` and `fxQuotedAt`, and kept
`charged_currency` CHF beside a rate. `checkout_payment_settle` then failed on `booking_payments_fx_complete` and
`booking_payments_fx_currency_pair`. The consumer acks a non-P0002 SQL error, so a paid EUR/USD/AED customer got a booking that
stayed `pending`. Now: rate = presentment amount / charged rappen, quoted_at = the session time, `charged_currency` = the paid
currency when the table allows it (EUR, USD, AED); any other currency keeps CHF and records only the presentment currency. The
legacy `currency_conversion` branch got the same fix. Unit tests added; the real-DB spec proves it.

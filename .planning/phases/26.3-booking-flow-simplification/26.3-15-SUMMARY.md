# Phase 26.3 Plan 15: Checkout part 1 Summary

`/{locale}/checkout` now reads the trip from the URL, quotes it in the browser through `POST /api/quote` with Search Box `retrieve` kinds (airport fee and guards stay server-side), shows a trip strip with an inline editor, and Section 1 "Choose your class" with every state. `/checkout/trip|details|payment` forward to `/checkout` keeping the query. Every checkout and pay-link string exists in four languages.

## What was built

- **page.tsx** (server): `parseTripQuery` only, no quote, no `readVamosTrip`. Step pages `redirect()` to a fixed own path plus the same query (unknown locale falls back to en, no host).
- **CheckoutPage** (client): state for trip, quote, selected class, editor; quotes once on mount (StrictMode-guarded, newest answer wins). Class chosen writes `class=` to the URL; selection survives a reload. `useCheckoutFlow()` exposes trip, quote, phase, selection, `pricingNotLive`, editor open/close, `resumeBookingId` setter, `resuming` (resume= without a trip: no missing-trip errors) and `applyTrip` for plan 19. Empty slots `CheckoutSectionsSlot`, `CheckoutRailSlot`, `CheckoutBarSlot` render nothing until plan 19.
- **fetchQuote**: retrieve kinds from `fid`/`tid` with `gs` (fresh uuid if missing), never `is_airport`. On `place_unresolved` (or missing ids) it looks the text up again with `/api/geo/suggest` under a fresh session and asks once more (research assumption A3). Turnstile: on `turnstile_required` the error state shows the widget and re-quotes with the token.
- **TripStrip / TripEditor**: back chevron and arrow mirror in RTL; editor order From, Flight (airport only), To, When, Travellers; validation like home (required, flight format, same place); UPDATE PRICES re-quotes with the section in loading state, replaces the URL, clears a class that became too small, keeps state for the later contact fields; error keeps the editor open with the matching `quote.error.*` text and restores the previous prices; Escape/CANCEL close and return focus to Edit trip.
- **ClassSection**: `VehicleCard` per class (vertical >=681, rows <=680), check disc on the photo, title disc turns to the yellow check disc, too-small cards disabled at 42% with "Seats up to n" / "Takes up to n bags" (fare-table reasons use the existing `quote.class.*` copy), loading, error (danger Alert + TRY AGAIN), pricing not live (info Alert), empty ("No class fits this trip" + EDIT TRIP), idle (incomplete URL: editor opens with the gaps named, no quote sent).

5. **[Rule 1] Found by the spec and fixed:** `checkout.tripWhen` was missing (label showed the raw key); clearing From/To in the editor restored the old text (PlaceCombo calls `onPlace(null)` after `onClear`).
6. **playwright.config.ts** (not in the plan's list): spec added to the CI `testIgnore`, same as every spec that boots Next.
7. **Pricing not live** is detected two ways: error code `pricing_not_live`, or an ok answer where `pricing_live` is false or every class total is null. Cards then show `CHF 000` with the info Alert; `pricingNotLive` in the flow context tells plan 19 to disable PAY.

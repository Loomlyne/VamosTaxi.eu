## Deviations from Plan

1. **[Rule 1 - Bug] VAT scale.** Plan text says "vat 810 bps"; `lib/checkout/vat.ts` divides by 1000 (81 = 8.1 %). 810 would be 81 %. Tests use 81; 100.00 − 10 → 97.29 holds.
2. **[Rule 1 - Bug] Negative coupon line cannot be stored.** `public.rappen` is `integer check (value >= 0)` and `tg_snapshot_lines_reconcile` casts each line amount to it and requires the sum to equal `total_rappen`. Writing checkoutCharge lines verbatim would fail the insert whenever a coupon applies. Added `snapshotLinesFromCharge`: discount comes off the fare line, then extras (each keeps `params.list_rappen`), coupon line stored with `amount_rappen: null` and `params.discount_rappen`. ChargeLine (display contract) keeps the negative coupon line as specified. Adds `seq`/`leg_seq` the trigger requires.
3. **[Rule 3] zurichLocalToUtcMs accepts optional `:SS`.** Existing lock fixtures (lock-to-rpc.test.ts, other tests) carry seconds; the quote schema itself only emits `HH:MM`. Also rejects out-of-range month/day/hour/minute.
4. **Coupon semantics in checkoutCharge.** Unlike payableRappen (where an amount coupon is already inside the lock's class net), checkoutCharge applies both coupon kinds, from `preCouponRappen ?? classNetRappen`, so the plan's 9729 case holds. Documented on the type; plan 09/10 must pass the lock's pre-coupon total.
5. **Legacy snapshot path:** the three-code filter on `policy.extras` is dropped on both paths (plan step 4); every `extraFares` code is recorded.
6. **Deprecations:** `extraIsOnForStep` deleted (no non-test importer; its two test assertions removed). `EXTRA_UI`, `extraUi`, `extraIsOn`, `lockHasExtra`, `extraFaresOn`, `recapExtraFares`, `recapExtras`, `extraRappenOutsideLock`, `catalogFromSurcharges` kept and marked `@deprecated 26.3 D-35 — removed by plan 26.3-21` (still imported by CheckoutClient.tsx, intent.ts, reprice.ts, extras route).
7. **Trip URL choices:** missing `bags` = 0; missing `pax` = required error on `travellers`; `pay` limited to `unpaid|failed|cancelled`; hidden params (fid, tid, gs, resume, pay, class, extras) drop silently to null/[] without a form error; `bags` is always emitted by buildTripQuery.
8. **selectableExtras** also excludes rows with `quantity_source = 'extra_stops'` besides code `extra_stop`, and always-on quote-priced rows.

# Phase 26.3 Plan 13: Ops extra names and Awaiting payment Summary

Extra names are machine-translated to de/fr/ar with Workers AI on save and stay editable per language; the ops board's default view is paid bookings and "Awaiting payment" lists every unpaid pending booking.

## Behaviour

- Save order: surcharge first, then labels in a separate staff call. A translation or label failure is logged as `extra_label_translate` (no text) and never fails the surcharge save.
- A typed language that differs from the stored value is a staff value (not in `machine_langs`) and is never re-translated. Machine languages are re-translated only when the English name changed or the value is missing. If AI is absent or fails, missing languages stay empty (public falls back to English).
- Output is trimmed, capped at 80 chars, German `ß` becomes `ss`; stored as text.
- Board: `isUnpaid = !paid && status === 'pending'`; foot text "Not paid yet"; empty state "No bookings awaiting payment." in en/de/fr/ar (other empty filters show the existing "Nothing booked" text).

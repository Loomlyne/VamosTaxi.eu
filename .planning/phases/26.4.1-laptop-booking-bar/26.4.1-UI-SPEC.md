> bottom of the hero, trip-type tabs removed.
> This file **supersedes 26.4 D-01 "laptop keeps the 26.3 box" for ≥1081 px only**. Everything else in
> `26.4-UI-SPEC.md` stays in force: bar + sheet at ≤1080 (unchanged), D-08/D-09 flight rules, one trip state,

## Layout contract

### Placement (≥1081)
- The bar is the last block of the hero content, full hero content width (hero inner gutter `clamp(16px,4.5vw,40px)`,
  so the card spans viewport − 80 px at ≥889), hero copy above it, the trust/review line below it — as picture 3.
- Card: `--vt-bg-surface`, `--vt-radius-xl`, `--vt-shadow-lg` (existing box values), padding `--vt-space-4` (16px)
  all sides, `max-width: none` (the 820px cap applies only to the box, which no longer renders at ≥1081).
- Removed at ≥1081: trip-type tabs (already gone since 26.3; must not return), any price, the "Step 2 · Choose your
  class" line, the old 152px flight-first column.
- Not docked on scroll at ≥1081 (docking is the ≤1080 bar only, 26.4 D-05).

### Field order (signed): From · Flight number · To · When · Travellers · SEE PRICES

| Track | Content | Width |
|-------|---------|-------|
| From | kicker `FROM` + 54px place combobox | `minmax(0,1fr)` |
| Flight | only after a pickup is chosen (D-09): airport pickup → required flight field; other pickup → `Add a flight number` ghost opener (44px, vertically centred on the 54px field line), which opens the optional field with `Optional` tag | `auto`, field min 168px, max 232px. Track absent before a pickup is chosen |
| Swap | `IconButton arrow-left-right` 44px, centred on the field line | 44px |
| To | kicker `TO` + 54px place combobox | `minmax(0,1fr)` |
| When | existing `WhenPicker` (kicker `WHEN`, 54px trigger) | `minmax(180px,0.9fr)` |
| Travellers | kicker `TRAVELLERS` + 54px compact trigger: `users` + passengers figure · `luggage` + bags figure + `chevron-down` (figures only, Qurova, `.vt-dir-keep`) | 148px |
| CTA | `SEE PRICES` primary 54px, `iconEnd="arrow-right"`, never truncated, never disabled | `auto`, min 176px |

- Column gap `--vt-space-3` (12px); kicker → field 6px (existing kicker rule, unchanged). Items `align-items:start`;
  swap and CTA take `margin-block-start` equal to the kicker line (24px; swap 29px as today) so every control sits on
  one 54px line.
- The compact travellers trigger carries `aria-label="{{ travSummary }}"` (existing "1 passenger · 0 bags" pattern,
  already in the dict) and the same `title`. Tapping opens the existing panel; at ≥1081 the panel is
  `inline-size: 320px`, anchored `inset-inline-end: 0` under the trigger (not stretched to the 148px trigger).
- Suggestion list under From/To: `min-inline-size: 360px`, anchored to the field's inline-start.
- DOM order stays `from, flight, to, swap, when, trav, cta, note`; visual order via `grid-template-areas`. Tab order
  = DOM order.
- Swap sits between Flight and To when the flight track shows **[discretion]** (signed order keeps Flight right
  after From; alternative: hide swap while the flight track shows).

### Widths
| Viewport | Layout |
|----------|--------|
| ≥1272 (1440, 1280) | **One row**: `from flight swap to when trav cta`. The flight track collapses when absent |
| 1081–1271 (1181, 1180, 1081) | **Two rows**, same card: row 1 `from flight swap to`; row 2 `when trav cta` (When `1fr`, Travellers 148px, CTA auto). Row gap `--vt-space-3` |
| ≤1080 (1024, 768, 390) | 26.4 bar + sheet, **unchanged** |

- Why 1272 **[discretion]**: at 1181 the card content is ~1069px; with the flight track, swap, travellers and a
  German CTA (~215px) the three flexible fields would drop to ~135px each. From 1272 (card content ≥1160px) they keep
  ≥168px. Implement as `@media (min-width:1272px)` on the one-row template.
- Nothing scrolls sideways at any width. Long values and placeholders ellipsise inside their field (existing
  `text-overflow:ellipsis`), with the full value in `title`. Kickers are `nowrap` + ellipsis. The CTA label never
  truncates.
- Errors and hints render under their own field and grow the card downward; other fields do not move (start
  alignment). The flight hint may wrap to two lines in its track.
- Trust line (`Price fixed before you pay` · `Flight tracked` · `Free cancellation window` TBC pill) stays as one
  start-aligned line under the row inside the card, 8px above it **[discretion — picture 3 shows no line; owner may
  drop it at ≥1081]**.

## States (all reachable by using the bar)

| State | Look |
|-------|------|
| Empty (page load, after reload) | Placeholders `Pickup address`, `Drop-off address`, `Select date & time`; travellers `1 · 0`; no flight track |
| Filled | Values in `--vt-text-primary`; place icon per type (existing `pickupIcon`) |
| Hover | Field border `--vt-grey-300`; CTA one colour step (DS) |
| Focus | Fields: charcoal border only (`.vt-input--focus{box-shadow:none}`). Swap, travellers trigger, opener, steppers, CTA: `--vt-ring` |
| Press | `translateY(1px)` |
| Airport pickup | Flight track appears (140ms fade, existing) with required field, `plane-landing`, hint `We track it and move the pickup if you land late` |
| Other pickup | Flight track shows the opener; after tap, optional field with `Optional` tag and hint `It does not change the price.` |
| Error (per field, on SEE PRICES or blur) | Border `--vt-danger`, message under the field in `--vt-danger` (`role="alert"`, `aria-invalid`), focus moves to the first invalid field in DOM order. Messages are the existing 26.3/26.4 strings |
| Travellers open / When open / suggestions open | Existing panels, positioned as above |
| Submit | `submitBox` validates, then `/checkout` with the trip in the URL exactly as 26.4. No loading state in the bar |

- **Same trip state** as the ≤1080 bar/sheet: resizing across 1080 or 1272 keeps every entry and any error; an open
  panel closes silently when its layout switches. Reload starts empty (26.4 signature).

## Typography

Exactly four sizes. Exactly two weights (400 and 600). No other size or weight on this page.

| Role | Size | Token | Weight | Line height | Usage |
|------|------|-------|--------|-------------|-------|
| Label | 14px | `--vt-body-sm` | 600 | 1.45 | Kickers, table headers, page subtitle, field labels |
| Body | 16px | `--vt-body-md` | 400 | 1.6 | Table cells, helper copy, dialog body, empty/error body |
| Heading | 20px | `--vt-heading-3` | 600 | 1.18 | Pane headings, dialog titles, recap line names |
| Display | 26px | `--vt-heading-2` | 600 | 1.18 | Page title; preview payable total figure |

Page title uses Display. Table cells use Body. Kickers and table headers use Label (uppercase + `--vt-label-tracking` on kickers / headers / badges only). Display and Heading use Qurova (`--vt-font-display`). Body and Label use Poppins (`--vt-font-body`).

## Color

60 / 30 / 10 explicit. Hex from `CLAUDE.md` only: yellow `#FDC20B`, charcoal `#1E1F1F`, grey `#DEDEDE`. Never invent a colour.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--vt-bg-surface` / white page (`--vt-white`) | Page background, tables, overlays, editor surfaces |
| Secondary (30%) | `--vt-charcoal-900` (`#1E1F1F`) | Ops sidebar + inverse rail cards |
| Accent (10%) | `#FDC20B` / `--vt-accent` | Reserved list below only |
| Destructive | `--vt-danger` | Discard draft, delete-row trash, Publish error text |

Hairlines use `--vt-border-subtle` (`#DEDEDE`). Inverse rail type uses `--vt-text-inverse`. Text on accent uses `--vt-text-on-accent` (`#1E1F1F`).

**Accent reserved for:** Publish fare book button, active left-tab kicker, preview payable total figure, Live book badge.

Not accent: overlay saves, Add row, Keep editing, Create test unpaid, inactive tabs, inputs, table chrome.

No glow. No `--vt-shadow-accent`. No tinted yellow (`--vt-yellow-50` / `100` / `200` / `300`, `--vt-yellow-600` / `700`). Hover / press / focus: fill or border change, `translateY(1px)` on press, charcoal shadow tokens, `--vt-ring`. Inputs: charcoal border only — no yellow ring (keep `.vt-input--focus{box-shadow:none}`).

| Name | Width | Shape |
|------|-------|-------|
| Phone | max-width 767px | Same controls. Left-tab rail scrolls horizontally. Tables swipe. Preview stacks under VAT. |
| Tablet | 768–999px | Tabs remain visible. Editor stacks above the rail. Rail is not sticky. |
| Desktop | min-width 1000px | Three columns: left tabs · table/editor · sticky rail. Rail `position: sticky`. |

Title: one line, `white-space: nowrap`. Currency is CHF only — no currency chips. Trash is `--vt-danger` on every table last-column ghost `IconButton`.

Every scroller (tab rail, table wrapper, preview stack) sets `data-scroll-native` (and `data-lenis-prevent` where the panel owns scroll).

Logical properties only (`margin-inline-start`, `inset-inline-end`, `padding-inline`). Arabic `dir="rtl"` from the locale runtime.

### Desktop (min-width 1000px)

1. **OpsSidebar** (secondary charcoal) + main surface (white).
2. **Header:** Display title (nowrap) at inline-start. At inline-end: Discard draft (destructive) then Publish fare book (accent). Header is the primary focal row.
3. **Body grid:** left tabs (five) · pane table/editor · sticky rail.
4. **Sticky rail:** VAT % field, then draft preview (inverse card). Preview recap under VAT. Create test unpaid under the recap. Publish is **not** in the rail.

### Tablet (768–999px)

Same header. Tabs in a horizontal row under the header (not a separate route). Editor full width. Rail full width under the editor (VAT, then preview). Tables keep columns; wrapper swipes if needed (`data-scroll-native`).

### Phone (max-width 767px)

Same controls, no hidden editing. Title nowrap. Header actions wrap under the title (Discard draft, Publish fare book) with 8px gap; 44px minimum on icon-only controls. Tab rail horizontal scroll (`data-scroll-native`). Tables swipe (`data-scroll-native`). Preview stacks under VAT in the rail. Phone Filter/View may be icon-only **with** aria-label from the copy table.

## Interaction

- Overlay **Save route / Save class / Save band / Save region / Save rule / Save surcharge / Save coupon** writes **draft only**. Public, ops board, checkout, Stripe, and new mail do not change.
- **Publish fare book** is the only flip. Opens a dialog on this page (not a route). All-or-nothing. Next quote uses the new book with no wait. After success, a new draft is cloned from live.
- **Discard draft** confirms first. Last published stays live. History does not change.
- VAT % lives on the sticky rail and waits for the same Publish click (no instant public PATCH).
- Preview always uses the **draft**. Inputs: Mapbox From / To, when, class, pax, extras, coupon. Recap order: start, km, bands, region %, extras, VAT, total. Payable floors at `CHF 0.00`. Coupon before VAT.
- **Create test unpaid:** admin on this page only. Typed contact email. Unpaid, no Stripe session, no mails. Ops board marked test. Pay off on public `/bookings`. Uses the draft even if not published. Same lock expiry as real unpaid.
- Left tabs switch panes in place. Distance rules owns add / hide / remove class. Class required fields: name, start, per-km, max pax. No first-X-km field.
- Fixed route save without Mapbox From and To is blocked (copy table). A→B and B→A are separate rows. Empty class on a route = that class not offered.
- Surcharges pane: **rules** table, then **surcharge** rows that pick one rule. From / To / zone / service area are Mapbox. Timezone is Europe/Zurich as product law — not a field.
- Coupons: percent off **or** fixed CHF off, dates / cap, all classes, one coupon per booking. Code case-insensitive, trim spaces. Public cannot use a new coupon until Publish.
- History: empty before first Publish. Cannot delete rows. Current live marked. Row: Zurich date/time, who published, gap-free, View changes. Cannot edit a past book in place — Clone into draft, then edit. Re-publish uses the same Publish fare book dialog.
- Trash: last-column ghost `IconButton`, `--vt-danger`, aria-label from the matching delete confirm.
- Two admins: last successful Publish wins; the other sees the exact Publish error.
- No unpublish back to `CHF 000`. Only a later Publish replaces the book.

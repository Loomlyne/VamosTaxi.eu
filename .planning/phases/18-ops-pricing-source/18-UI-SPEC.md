## Interaction

### Draft / Publish (D-01…D-14)

- Typing is **not** a draft. Leave without Save → gone.
- **Save route / Save class / Save band / Save rule / Save surcharge / Save coupon / Save VAT** writes the **draft only**. Public, ops board, checkout, Stripe, and new mail do not change.
- **Publish fare book** is the only flip. Opens a `Dialog` on this page (not a route) with the **change list** vs the last published book. All-or-nothing (D-09). Next home quote, checkout recap, confirmation, ops amounts, Stripe charge, and new booking mail read that book immediately.
- After success, `/pricing` shows the **live book**. Do **not** fork a draft in the Publish transaction. The next Save starts a new draft (D-03).
- Gaps and conflicts: Dialog names the **exact** problem and **Fix this** jumps to that section/overlay (switch tab + open the row overlay, or focus VAT). Failed Publish **keeps the draft**. Public unchanged. Fix and Publish again, or Discard and start from the live book (D-08).
- **Discard draft** confirms first. Last published stays live. Page shows the live book. Do not clone on Discard (D-06).
- Draft mark only when a **saved** draft exists (D-05).
- Quote lock is **fixed 24 hours**, not a field. Unpaid keep the locked old amount until then, then auto-cancel and must quote again. Paid trips keep the snapshot (D-13).
- VAT % lives on the sticky rail, persists only via **Save VAT**, and waits for Publish. No keystroke write. No instant public PATCH (D-01 / D-12).
- Header EUR/USD on **public** is display only. This ops page is CHF only. Charge and receipts CHF (D-27).

### Fixed routes (D-20)

- Kind picker in the add/edit Dialog: Mapbox place→place **or** canton→canton.
- Place→place: Mapbox From and To required to Save. A→B and B→A are separate. Airport terminal ≡ saved airport pin.
- Canton→canton: both cantons required to Save. Empty canton table is valid and does **not** block quotes.
- Mapbox suggest is worldwide (no `country=CH`, no canton tick-list fence) (D-26).

### Distance & classes (D-15…D-18, D-29…D-33)

- Recipe: **start** (once) **+ (all km × per-km) + bands on top**. A 1 km trip uses the same recipe. No minimum fare. No first-X-km.
- Bands optional. CHF per km in the slice **on top of** class per-km. From inclusive, To exclusive. Open last band allowed. **Overlap blocks Publish**.
- Admin adds / edits / deletes **any** class. Name is what they typed. After Publish, public cards use that name, R2 photo, seats, bags, price from this book. No hardcoded Economy / Business / First / Van board.
- Required to Publish a class: **photo (R2), name, start, per-km, max passengers, max bags**. Photo: upload / replace / delete. No `data:` embeds. No photo → cannot Publish.
- Hide from public still exists: listed, Select off, `CHF 000`. Delete + Publish → gone.

### Surcharges (D-34, D-35, D-22, D-23, D-25)

- One list. Add Dialog = type + only that type’s fields + “what this does”.
- Checkout extras: amount × quantity, after ride money, before VAT. Delete + Publish → gone from checkout.
- Meet & greet / free wait always on. Meet CHF 0 included. Free wait hours field (1 h now). Extra wait per hour not in Stripe pay-now. No silent debit.
- **No** night / weekend / holiday types. Quote lock is **not** a row.

### Coupons (D-24)

- Percent or fixed CHF, dates/cap, all classes. Coupon before VAT. One per booking. Codes case-insensitive, trim spaces. Payable floors at `CHF 0.00`.

### Shared chrome

- Left tabs switch panes in place. Four tabs only. **No History tab.** No history list. No Re-Publish of an old book.
- Trash: last-column ghost `IconButton`, `--vt-danger`, aria-label from the matching delete confirm.
- Two admins: last successful Publish wins; the other sees the exact Publish error; draft kept.
- No unpublish back to `CHF 000`. Only a later Publish replaces the book.
- Dual DC: edit `app/ops/` then sync. Agent does not click Publish. Agent does not `supabase db push`.

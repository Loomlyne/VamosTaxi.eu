- Content scan of everything under `app/`: no key, no token, no Supabase or workers.dev address, no
  real customer. E-mail addresses are `info@vamostaxi.site` and `@example.com` samples. What an
  outsider learns: the dashboard's screens and the names of the `/api/staff/*` routes. Every such
  route answers 401 without a staff session.
- `/app/ops/*` is served straight from the asset store, not through the Worker
  (`wrangler.jsonc` `run_worker_first` lists only `/app/pages/*`, `/app/home/*`, `/dev`). So these
  answers carry **no security header at all** on either host: no CSP, no `X-Frame-Options`, no HSTS,
  no `nosniff`, no `noindex` (`/app/pages/*` has them all). `robots.txt` does disallow `/app/`.
  On the dashboard host the raw `ops.dc.html` can be put in a frame on another site; the sign-in
  cookies are SameSite=Lax, so the framed console is signed out. Low.
- Same for `/app/*.js` (`vamos-ops-data.js` is sample data for the mocks, no real rows).

**Smallest fix (batch C, `wrangler.jsonc` + `middleware.ts`):** add `/app/ops/*` to
`run_worker_first`; in the middleware answer 404 for `/app/ops/*` on the public host, and on the
dashboard host stamp the security headers and `X-Robots-Tag: noindex` on it. No public page
imports anything from `/app/ops/`. Test: public `/app/ops/ops.dc.html` → 404; dashboard
`/app/ops/ops.dc.html` → 200 with CSP and `X-Frame-Options: DENY`; dashboard `/login` still boots.

## F17 — Arabic font is blocked (seen on live by the control session, confirmed in code; no edit)

`app/vamos-locale.js:369` loads `https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic…` when the
language is Arabic. The live CSP has `style-src 'self' 'unsafe-inline'` and no `font-src`, so the
stylesheet (and the font files on fonts.gstatic.com) are refused. Arabic pages fall back to the
device's own Arabic font. Not a security hole; a display fault and, if allowed instead, a privacy
point (the visitor's IP goes to Google).

Smallest fix: serve Noto Sans Arabic from our own host (`assets/`, like the other fonts) and drop
the Google link, so the CSP stays closed. Owner question; belongs with batch C.

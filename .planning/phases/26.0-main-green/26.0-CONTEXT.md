### D-02 `/dev/*` gallery reachable in tests only — test-only switch
One helper (e.g. `lib/dev-gallery.ts` `devGalleryEnabled()`), true only when
`NODE_ENV !== "production"` AND `VAMOS_DEV_GALLERY === "1"`. Used by `isMockPublicPath` /
`should404MockLeak` (middleware) and `app/[locale]/dev/layout.tsx`. `worker.ts` keeps 404ing.
The flag is never put in `wrangler.jsonc`. Specs set it only in their own spawned `next dev` env.
Proof required: a vitest that `devGalleryEnabled()` is false under `NODE_ENV=production`, and a
check that `https://vamostaxi.site/dev` and `/dev/home/services` still answer 404 (read-only GET).
The darwin baselines of the gallery specs date from 2026-08-30: where they no longer match, that
is reported to the owner with the diff images, not rebaselined silently.

### D-06 SiteHeader Mac-only failures — pin the media feature to "reduce"
Root cause (proved): `SiteHeader.css` uses `@media (prefers-reduced-transparency: reduce)` for
the open-menu scrim (0.86 vs default 0.62 alpha). GitHub's `macos-26-arm64` image reports
"reduce"; this Mac does not (51 vs 108 grey). CDP experiment: forcing "reduce" → 103/103 pass;
forcing "no-preference" → the same 48 fail. Fix: a shared helper in
`apps/web/tests/support/` that sets `Emulation.setEmulatedMedia` `prefers-reduced-transparency:
reduce` for every visual spec. No screenshot is retaken.

### D-07 Database tests use the Worker's client options (control session, 2026-09-29)
VT-26-0733 passed every test while live failed: the test database client parses arrays, the
Worker's (`fetch_types: false`, `prepare: true`, `max: 1`) does not. Rule: every test that
talks to the database through app code, or that exercises SQL the Worker calls, opens its
connection with the same options as `packages/db/src/identity.ts` `client()` — through one shared
test helper that imports or mirrors those options and fails if they drift. At least one test
round-trips a `text[]` result and a `text[]` param through that helper, so it goes red on main
today and green once the 26.3 fix lands.
Do not edit `packages/db/src/identity.ts`, `packages/db/src/public.ts` or `apps/web/lib/checkout/**`
(the fix itself belongs to the 26.3 session). If the helper needs an export from those files,
mirror the options in the test helper with a drift check instead, and tell the owner.

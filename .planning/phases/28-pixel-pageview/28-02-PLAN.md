## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Meta | Page address (dl), referrer (rl) and cookies leave our site |
| Cached HTML → many visitors | The same HTML is served to people with different choices |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-06 | Information Disclosure | dl on checkout/confirmation/pay link | mitigate | Allow-list (never a deny-list), vt-digit rule, query key rule, hash rule; parity table with the server twin |
| T-28-07 | Information Disclosure | rl carries a denied same-site address | mitigate | referrerAllowed fails closed; header change follows in 28-04 |
| T-28-08 | Information Disclosure | automatic matching / automatic events reading form fields | mitigate | autoConfig false with id and globally before init; init with one argument; no userData; proven with Meta's real script in 28-07 |
| T-28-09 | Information Disclosure | pixel for a visitor who refused | mitigate | Loads only after server state says marketing true; event alone never boots; revoke is final for the page; flags off by default |
| T-28-10 | Information Disclosure | queued events replayed | mitigate | Never grant after revoke (source pin) |
| T-28-11 | Tampering | another fbq on the page | mitigate | Existing window.fbq → do nothing |

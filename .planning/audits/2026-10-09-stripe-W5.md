# W5: Database settlement and money tables (reviewer W5, report only)

Date: 2026-10-09. Scope: `packages/db/supabase/migrations` (143 files) and `packages/db/supabase/tests` (109 files), read only. Nothing applied, no live connection, no file changed except this report. Migration `20261007320000` is treated as held (not applied live).

Method: for every function the LATEST `create or replace` across all migrations was read; the grant sequence (revoke/grant per signature, default privileges in `20260823000002_roles_and_helpers.sql:108-129`) was replayed with a script; every `security definer` body was scanned for `set search_path`; runtime dynamic SQL was searched. Line numbers are in the named migration file. "unverified" = needs the live read or a Worker read that I was not allowed to do here.

Roles: `anon`, `authenticated`, `service_role` (Supabase), `vamos_edge` (Hyperdrive login, can SET ROLE into the rest), `vamos_public`, `vamos_guest` (manage-token), `vamos_staff`, `vamos_checkout` (public checkout route), `vamos_system` (queue/cron/ops writers).

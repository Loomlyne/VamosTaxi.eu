# Sketch Manifest

## Design Direction
Same Vamos design system (yellow #FDC20B accent, charcoal, Qurova + Poppins, pill fields,
16px cards), no glow, no tinted yellow, `CHF 000`. Goal: fewer screens and inputs from the
home card to payment, and layouts that are genuinely phone-, tablet- and desktop-shaped.

## Reference Points
Current live flow on vamostaxi.site (home card → /checkout/trip → /details → /payment).
